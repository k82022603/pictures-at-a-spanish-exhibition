# 작곡일지 2026-08-21

**주어가 「곡」이다.** 바이브로그가 나를 되짚는다면 이쪽은 곡에 무슨 일이 있었는지를 적는다.

**오늘 곡에 일어난 일은 하나다 — 0악장이 다시 태어났다.**

---

## 1. 왜 다시 만들었나

**저작권 대조 때문이다.** 그런데 그것은 계기였을 뿐이고, **드러난 것은 설계의 약점**이었다.

`07` 3장이 이 곡의 성부 역할을 이렇게 못박았다.

> **베이스는 걷는 몸이고, 주제는 보는 눈이다.**

**그런데 기존 0악장은 보고 나서 걷는다.**

| 기존 0악장 | |
|---|---|
| 0~12초 | 피아노가 주제를 말한다 — **본다** |
| 12초~ | 베이스가 들어와 조성을 선포한다 — **걷는다** |

**여행자는 걷기 시작한 다음에 본다.** 순서가 거꾸로였다. 넉 달 동안 아무도 그것을 못 봤고, **Suno 의 지문 대조기가 그것을 짚었다.**

> **그 자리가 원곡에 가장 가까운 자리였기 때문이다.** 이 곡의 컨셉은 무소르그스키를 스페인으로
> 옮기는 것인데, **0악장만 러시아 피아노 독주 그대로**였다. 지문에 걸린 이유와 서사가 어긋난
> 이유가 **같은 하나**다.

## 2. 무엇을 바꿨나

### 2.1 앞에 세 마디를 덧댔다 — 베이스 혼자

```python
PRE0 = [("Bb", 5), ("Gm7", 6), ("Bb", 6)]      # 17박 = 10.2초
```

**B♭ → Gm7 → B♭ 의 왕복이다.**

**왜 이 진행인가.** 주제 A 는 6도(G)로 시작한다. 그래서 첫 화음이 B♭ 인지 Gm 인지 **원래 애매하다.** 기존 코드의 주석이 그것을 이렇게 적고 있었다 —

> *"첫 음 B♭1 하나가 곡의 조성을 선포한다. 주제가 6도(G)로 시작해 첫 화음이 B♭인지 Gm인지 애매한데, 그 애매함을 푸는 것이 이 한 음이다."*

**기존 판에서는 그 애매함이 생기기도 전에 풀렸다** — 피아노가 먼저 말하고 베이스가 뒤에 확인했으니까.

**새 판에서는 베이스가 혼자 그 왕복을 해 보인다.** B♭ 로 시작해 Gm7 으로 흔들리고 다시 B♭ 로 착지한다. **애매함을 만들었다 푸는 것을 열 걸음 동안 보여준다.**

### 2.2 베이스 세 줄을 새로 썼다

```python
BASS_PRE = [
    [34, 41, 38, 45, 41, 46, 43, 39, 43, 38],                # Bb   첫 음이 조성이다
    [43, 39, 46, 43, 50, 46, 43, 39, 41, 45, 43, 39],        # Gm7  위로 걸어 오른다
    [34, 41, 45, 41, 46, 43, 50, 46, 43, 39, 38, 34],        # Bb   돌아와 착지
]
```

**BL-25 규칙 셋 중 둘을 지켰다.**

| 규칙 | 지켰나 |
|---|---|
| (1) 8분음표로 한 번도 멈추지 않는다 | **지켰다** |
| (2) B♭1~G3 (MIDI 34~55) 을 오간다 | **지켰다** — 34~50 |
| (3) 주제 A 가 오르면 베이스는 내린다 | **해당 없음** — 주제가 없는 구간이다 |

**(3)이 해당 없다는 것이 이 세 줄의 성격을 정한다.** 곡의 다른 어디서도 베이스는 주제에 대해 움직인다. **여기서만 혼자 움직인다.** 그래서 위로 한 번 올랐다 내려오는 아치 모양을 줬다 — **혼자 걷는 사람의 걸음**이다.

**첫 음이 34(B♭1)인 것은 고른 것이 아니라 정해진 것이다.** 그 한 음이 곡의 조성을 선포한다.
**마지막 음도 34다.** 그래서 이어지는 기존 첫 줄(`[34, 45, 43, ...]`)과 이음매가 없다.

### 2.3 화성 진입을 10.2초로 옮겼다

```python
T0H = T0 + BT * 17.0                       # 17박 = 10.2초
lay_chords(PROG0[3:], T0H, ...)            # 앞 세 마디는 화성 없이
```

기존은 11.5초였다. **1.3초 앞당겨졌다.** 우연이다 — 17박이라는 숫자에서 나왔다.

### 2.4 주제 A 가 여섯 번에서 네 번으로 줄었다

| | 기존 | 새 판 |
|---|---|---|
| 피아노 독주 제시 | **2회** | **0회** |
| 화성 위 재현 | 3회 | **3회** |
| 여섯 번째 (38.5초) | 1회 | **1회** |
| **합** | **6회** | **4회** |

**줄어든 둘이 정확히 「벌거벗은 제시」였다.**

**11박 간격은 그대로 뒀다** — `+1, +12, +23, +45`. 이 곡의 엔진(프레이즈 9박 ↔ 마디 11박)이 코드에 박힌 자리이고, **34번 칸을 건너뛰는 것**도 그대로다. 그 칸이 베이스 정점 G3 구간이라 주제를 얹으면 뺏는다.

> **이 판단은 2026-08-08 에 이미 내려져 있었다.** 새 판은 그 판단을 **그대로 물려받았다.**
> 앞을 바꿨지 뒤를 바꾼 것이 아니다.

### 2.5 드럼이 아홉 번째 마디부터

```python
if _i >= 9:      # 기존은 _i >= 6
```

**앞 세 마디가 늘었으므로 셋을 밀었다.** 결과적으로 **드럼이 들어오는 절대 시각은 거의 같다.**

**「베이스가 조성을 선포하는 자리를 드럼이 뺏으면 안 된다」**는 기존 주석의 원칙이 새 판에서 더 강해졌다 — 이제 그 자리가 **곡의 첫 10초**다.

## 3. 손으로 정한 값 — 왜 그 숫자인가

| 값 | 왜 |
|---|---|
| `PRE0` **17박** (5+6+6) | **10.2초.** 기존 피아노 독주 구간(12초)과 비슷하게. 그리고 전체 82.5박 = **49.5초**로 0악장 50초 칸에 맞는다 |
| `seed=20260822` | 기존은 `20260805`. **바꿔야 한다** — 같은 씨앗이면 앞 세 마디가 늘어난 만큼 뒤가 밀려 기존과 다른 소리가 나는데, 그것이 「의도한 변경」인지 「씨앗 충돌」인지 구분이 안 된다 |
| 보이싱 `53~65` | **그대로.** 목소리 자리(F4~F5)를 비우는 값이고 0악장에만 걸린 결정이 아니다 |
| `vel` · `ring` 네 값 | **그대로** — 0.70/1.8 · 0.66/1.8 · 0.72/2.0 · 0.62/2.2. 2026-08-08 검수 판정으로 정해진 값이다 |

> **「그대로 둔 것」을 적는 이유.** 새 판을 만들 때 손댈 수 있는 값이 스무 개쯤 있었고
> **넷만 바꿨다.** 나머지를 안 바꾼 것도 결정이다 — **한 번에 하나만 바꾼다**(`13` 문서).

## 5. 곡에 남은 것

**기존 0악장은 죽지 않았다.**

| | |
|---|---|
| `전곡화성.py` | **그대로.** 기존 0악장이 들어 있다 |
| 승인 flac | **그대로.** `전곡 - 3악장 d 승인 9m40s.flac` |
| 새 0악장 | **별도 파일** `0악장안A.py` |

**우리 자체 합성판에서는 기존 0악장이 여전히 정본이다.** 바뀐 것은 **Suno 에 넘기는 판**이다.

> **다만 이 상태는 오래 못 간다.** 언젠가 둘 중 하나를 정본으로 정해야 하고,
> 그때 `전곡화성.py` 를 고치면 **T-07 규칙상 1악장까지 함께 재야 한다** —
> `prev=LAST` 로 화성이 이어지기 때문이다. **오늘은 거기까지 안 갔다.**

## 6. 오늘 곡에 대해 배운 것

**주제 A 는 옷을 갈아입으면 다른 곡이 된다.**

같은 열한 음이 —

| 악장 | 입은 옷 | 지문 |
|---|---|---|
| 0 | **피아노 독주** | **걸린다** |
| 2 | 나일론 기타 캐논 | 통과 |
| 5 | 두 주제 겹침 | 통과 |
| 9 | 총주 | 통과 |
| **0 (안 A)** | **베이스 뒤에 화성과 함께** | **통과** |

**지문 대조기는 선율이 아니라 소리를 본다.** 그리고 이 곡은 처음부터 **같은 선율을 열 번 다르게 입히는 곡**이었다. **0악장만 옷을 안 입고 있었다.**
