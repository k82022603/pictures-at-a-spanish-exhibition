## 4. ⚠ 결함 — 창법 지시서의 음이름이 틀려 있었다

`산출물/20260814 .../창법 지시서 - 여행자의 목소리.md` **2절**이
**「B♭장조 기준」이라 적어놓고 A♭장조로** 적혀 있었다. **온음 하나 낮다.**

```
틀린 것   F4 E♭4 A♭4 B♭4 F5 D5 B♭4 F5 D5 A♭4 B♭4
맞는 것   G4 F4  B♭4 C5  F5 D5 C5  F5 D5 B♭4 C5
```

| | |
|---|---|
| 왜 위험 | **부를 사람에게 그대로 건네는 종이**다. 통째로 틀린 조로 부른다. 그리고 틀린 표의 **E♭4** 는 확정 음역 F4~F5 밖이다 |
| 어디는 맞았나 | `CLAUDE.md` 6절 · `가이드반주.py` · `보컬시험.py` **셋 다 맞다.** 손으로 옮겨 적은 **문서 한 곳만** 틀렸다 |
| 어떻게 | **8-14 파일은 안 고치고**(R9) 수정판을 **새 파일**로 냈다 |

**그리고 그 수정판을 쓰다가 같은 종류의 실수를 한 번 더 했다.** 6절 「3도 위」를
**반음 셋으로 계산**해 `C♯5`·`A♭5` 를 적었다 — **음집합 밖이다.** 3도 위는 온음계 3도라
간격이 `3 4 4 3 4 3 3 4 3 4 3` 로 섞인다. 계산해서 확인하고 고쳤다.

## 5. 새로 드러난 미결 — 9:16 의 「두 목소리」

`05` 9.31.4절이 **주제 A 를 3도 올리면 주제 B** 가 되는 것을 실증했고 9:16 이 그 자리다.

```
아래   G4  F4  B♭4 C5  F5  D5  C5  F5  D5  B♭4 C5    ← 최고 F5
위    B♭4 A4  D5  E♭5 A5  F5  E♭5 A5  F5  D5  E♭5   ← 최고 A5
```

**A5 는 남성에게 F5 와 다른 자리다. 목소리 고르는 기준이 바뀐다.**
이번 시험에서는 **아래 목소리 넷만** 만들기로 하고 미결로 남겼다.
