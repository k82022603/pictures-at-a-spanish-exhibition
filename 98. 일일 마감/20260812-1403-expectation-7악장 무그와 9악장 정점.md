## 1. 7악장 — 왜 무그가 뒤에 있나

**원인을 코드에서 찾았다.**

| 성부 | 언제 울리나 | 세기 |
|---|---|---|
| 피아노 아르페지오 | **쉬지 않고** — 화음마다 6음, 100초 내내 | 0.30 / 0.38 |
| 무그 (그녀) | **네 마디마다 한 프레이즈** (약 1.9마디 길이) | 0.44 |

**연속인 것과 간헐인 것을 나란히 놓으면 연속인 쪽이 이긴다.** 게다가 믹스 페이더가 피아노 +6 dB · 무그 +2 dB 라 **4 dB 가 더 벌어진다.** 실측 「피아노가 4 dB 크다」가 이것이다.

### 손댈 곳 둘

**v3.4 가 8악장에서 배운 것을 그대로 쓴다** — *"주고받기는 「누가 나오는가」가 아니라 「누가 물러나는가」로 만들어진다."*

| # | 무엇 | 값 |
|---|---|---|
| ① | **무그를 키운다** | `vel` 0.44 → **0.62** (약 +3 dB) |
| ② | **무그가 노래하는 동안만 피아노가 물러난다** | 아르페지오 `0.38/0.30` → **`0.21/0.17`** (약 −5 dB) |

**②가 핵심이다.** 무그를 키우기만 하면 둘 다 커져서 악장이 두꺼워질 뿐이다. **피아노는 무그가 쉴 때 원래 세기로 돌아온다** — 물의 아르페지오가 사라지는 것이 아니라 **그녀가 말할 때 비켜주는 것**이다.

### 예상

| 지표 | 지금 | 예상 |
|---|---|---|
| 무그가 1등인 창 (2초 창 50개 중) | **1개** | **15~25개** |
| 1등 비율 | 피아노 98% | **피아노 50~65%** |
| 주역 교대 횟수 | 2회 | **12~24회** |
| 7악장 RMS | −17.6 dB | **−17.8 ~ −17.4** (거의 안 변함) |
| **8악장 RMS** (T-07) | −15.8 dB | **불변 ±0.1** |
| 7악장 조성 밖 음 | — | **불변.** 이 악장엔 F♯ 품은 화음이 없다 |

> **7악장 RMS 가 거의 안 변할 것으로 보는 이유** — 무그가 +3 dB 오르는 구간에서 피아노가 −5 dB 내려간다. **총량이 아니라 배분을 바꾸는 것**이다. **RMS 가 크게 오르면 ②가 안 걸린 것이다.**

## 2. 9악장 — 터질 자리에 드럼이 없다

**시간표를 그려보고 찾았다.**

```
 544.05  Ebmaj7   4박   ← 드럼 bar 5
 547.86  F7sus4   2박   ← 드럼 없음  ┐
 549.76  F7       2박   ← 드럼 없음  ┤ 3.81초 공백
 551.67  Bb       4박   ← 드럼 bar 6 ┘
```

**두 번째 총주가 549.0 이다.** 곡의 정점으로 설계한 자리(무그 벨팅 · 두 주제 겹침)인데 **그 3.81초 동안 드럼이 한 대도 안 친다.**

### 왜 이렇게 됐나 — 같은 필터가 두 번째로 물었다

드럼 루프가 `if _nb >= 4` 로 거른다. 4/4 패턴을 2박 화음에 놓으면 넘치기 때문이고 **그 자체는 맞다.**

> **그런데 코드 주석이 이미 같은 사고를 기록하고 있다** — *"`PROG9` 의 7번째가 2박짜리 `F7sus4`/`F7` 이라 `_nb >= 4` 에서 걸러진다. 그런데 탐 롤 조건이 `n % 8 == 7` 이어서 하필 그 걸러지는 마디에만 걸렸고 — **탐 롤이 곡에 한 번도 안 들어갔다.**"*
>
> **그때는 탐 롤을 지웠고 이번엔 정점의 드럼을 지웠다.** 같은 필터, 같은 두 마디다.

### 손댈 곳 셋

**공백을 메우지 않는다. 공백을 쓴다.**

4악장이 배운 것 — *"0.013까지 비우는 구간이 있어야 그 뒤가 크게 들린다."* **547.86~549.0 은 이미 비어 있으므로 그대로 두고, 549.0 에서 터뜨린다.**

| # | 무엇 | 어디 |
|---|---|---|
| ① | **549.0 에 크래시 + 킥 + 오픈 스네어** | 공백이 끝나는 바로 그 지점 |
| ② | **549.76~551.67 에 2박 이음 패턴** | 정점에서 다음 마디로 이어준다 |
| ③ | **549 총주를 실제로 키운다** | 주제 A `0.76 → 0.88` · 무그 `0.50 → 0.58` |

### ★ 절대 지킬 것 — 566초를 안 건드린다

**v4.6 에서 같은 자리를 한 번 망쳤다.** 9악장 게인을 올렸더니 **9:26 해소가 흐려졌다**(Dm 의 F 0.397 → 0.281). 원인은 `PROG9` 한 바퀴가 47.6초라 **525초에서 올린 것이 566초 위에 그대로 얹혀 있기 때문**이었다.

> **그래서 이번에는 루프 안의 값을 하나도 안 건드린다.** `lay_bass` · `lay_chords` 의 게인은 그대로 두고 **549 근처에 낱개 이벤트만 더한다.** 크래시 여운은 길어야 4초이므로 553초에 끝난다.

### 예상

| 지표 | 지금 | 예상 | 판정 |
|---|---|---|---|
| **9:26 F♯ (566초)** | **0.168** | **불변 ±0.005** | ★ **1.4.8 수락 조건 ≥ 0.135** |
| **Dm 구간 F (해소)** | **0.397** | **불변 ±0.010** | ★ v4.6 에서 망쳤던 값 |
| 549 근처 가장 급한 도약 | 3.9 dB | **7~11 dB** | 이게 「터진다」 |
| 9악장 RMS | −15.5 dB | **−15.3 ~ −14.9** | |
| RMS 폭 | 6.4 dB | **6.4 ~ 6.8** | 상한 7.0 (`05` 9.14절) |
| 클리핑 | 0 | **0** | |
| 0~8악장 RMS | — | **불변** (9악장은 마지막이라 `LAST` 를 넘길 데가 없다) | |

> **9:26 을 예상에 적는 이유** — v2.6 에서 **그 악장을 안 건드렸는데도 값이 0.136 → 0.165 로 움직였고 안 번진 것은 운이었다.** 그때 세운 규칙이 **「판정 조건이 걸린 값은 그 악장을 안 건드려도 예상에 적는다」**이다. **오늘은 그 악장을 직접 건드린다.**
