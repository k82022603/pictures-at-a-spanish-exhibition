## 1. 4악장을 안 건드리려면 화음을 못 바꾼다

**제약을 먼저 세우고 시작했다.** 이유가 둘이다.

| | |
|---|---|
| ① `prev` 가 이어진다 | 3악장 마지막 보이싱이 4악장 첫 화음의 자리를 정한다. **화음 하나만 바꿔도 4악장 전체가 다시 짜인다** |
| ② 마스터 체인 | 테이프 드라이브가 **전곡 최대 봉우리**를 본다. 이 악장을 키우면 열 악장이 다 움직인다 |

**그래서 진행을 토막내 부르되 `prev` 사슬은 그대로 이었다.** 음이 같은 자리에 같은 시각으로 놓이고 **세기만 구간마다 다르다.**

**구조를 바꾼 뒤 `a` 판이 승인판과 비트 단위로 같음을 먼저 확인하고 시작했다.** 그래야 뒤 판들의 차이가 진짜 차이다.
