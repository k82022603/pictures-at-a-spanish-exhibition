## 3. 걸린 것과 고친 것

### (a) ★ 론다와 바르셀로나에 **이름이 같은 사진 열 장**

2005년 카메라의 일련번호가 한 바퀴 돌았다(`P1010078.JPG` 등).
사진 목록에 폴더가 없어서 **파일 이름으로 폴더를 되찾고 있었고, 열 장이 딴 도시
사진으로 바뀐 채 10분 영상이 나올 뻔했다.**

**`뼈대.py` 자기검사 4번(재사용이 표시돼 있는가)이 잡았다.** 겹치는 열 장이
「표시 안 된 재사용」으로 걸렸다.

**고친 자리** — 뼈대 쪽에서 조심하는 대신 **`사진목록.py` 가 「폴더」 칸을 적게 했다.**

### (b) 영상 렌더 — **세 번 구웠다**

| 판 | 걸린 것 | 값 |
|---|---|---|
| 1 | 소리가 늦는다 · 색 범위 | **+2048 샘플 (42.67 ms)** · `yuvj420p` |
| 2 | 색 범위 | 소리 0 샘플 · `yuvj420p` 그대로 |
| **3** | — | **전부 통과** |

- **2048 샘플은 AAC 인코더 지연**이다. **다섯 지점 전부 같은 값** — 드리프트가 아니다.
  영상만 굽고 소리를 마스터에서 따로 붙이니 **0 샘플**
- **`--pixel-format=yuv420p` 는 안 먹는다.** 프레임을 JPEG 로 뽑기 때문.
  답은 **`Config.setColorSpace("bt709")`**

### (c) 첫 판을 눈으로 보고 고친 것 둘

| 보인 것 | 고친 것 |
|---|---|
| **16초 자리에 몬세라트(바르셀로나)** — 마지막 도시가 맨 앞에 | 0악장은 **밝기로 고른다(어두운 것부터)** → 밝기 **15 → 99** 로 밝아진다 |
| 마드리드 벽화 위에서 악장 번호가 사라짐 | 로마 숫자 `I` 는 **획이 하나**라 안 보였다 → **「1악장」** |

### (d) ★ **C 70장이 그대로 영상에 들어가고 있었다**

첫 판은 파일 이름 순이라 **8/20 에 매긴 등급을 안 보고 있었다.**
**C 의 이유 넷 중 둘이 「사적 인물의 식별 가능한 얼굴」·「타인의 저작물」**이고,
그건 취향이 아니라 **내보내면 안 되는 것**이다.

### (e) 보정본을 지운 값이 드러났다

보정본 넷을 지우면서 **그 보정본에 기대어 C 였던 사진 둘이 갈 곳을 잃었다.**
**세비야 `PC110069`(타블라오)만 되살렸다** — 그 장면을 찍은 사진이 이것뿐이고
**V3 가 못박은 「그녀의 유일한 실재」가 이 한 장**이기 때문이다.
