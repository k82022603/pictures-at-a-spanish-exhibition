**렌더하기 전에 적는다.** 이 파일이 git 에 먼저 들어가야 「그때 예상했다」가 증명된다(`CLAUDE.md` 8절).

> **검수자** — *"7악장 ♩.=60→72 에서 ♩.=60→60 유지 + 8악장 전환 매끄럽게 음원 만드는 것 제일 앞으로."*
> *"7악장 플루우트 빠르기도 계산에 넣어줄것."*

빠르기를 되돌린다는 지시 하나인데, 이 악장에는 **마디 수와 8분음표 길이에 매달린 것이 셋**이다. 계산은 `99. 작업 스크립트/7악장타이밍.py` 가 악보에서 직접 셌다(렌더 없이).

## 1. 손으로 셀 수 없는 것부터 — 자리는 주는데 소리는 는다

| | 지금 (60→72) | **60 고정** | |
|---|---|---|---|
| 마디 | 55개 (2.000 → 1.667초) | **50개 (2.000초 고정)** | −5마디 |
| **그녀 (무그)** | 15번 · 한 번에 3.39초 | **13번 · 3.72초** | −2번 |
| 그녀가 부르는 간격 | 8.0 → **6.7초로 좁아짐** | **8.0초 고정** | **조임이 사라진다** |
| 그녀가 우는 시간 합 | 50.8초 | **48.4초** | **−2.5초** |
| **플루트** | 26번 · 한 번에 2.94초 | **25번 · 3.20초** | −1번 |
| **플루트가 우는 시간 합** | 76.3초 | **80.0초** | **+3.7초** |
| **플루트 : 그녀** | 1.50 : 1 | **1.65 : 1** | **+10%** |
| 가장 빠른 음 한 칸 | 0.278초 | 0.333초 | 20% 길어짐 |

### 이것이 오늘의 함정이다

**자리가 하나 줄었는데 플루트가 우는 시간은 오히려 3.7초 늘어난다.** 프레이즈 하나가 20% 길어지는 쪽이 자리 하나 줄어드는 것보다 크기 때문이다. **곱셈 둘이 반대 방향인데 크기가 다르다.**

그래서 **느리게 하면 플루트가 앞으로 나온다.** 8/13 에 검수자가 물린 것이 *"플루트가 메인이 되어버렸네"* 였고 그래서 세기를 0.55배로 줄인 판(J)이 채택됐다. **오늘 빠르기를 되돌리는 것은 그 판정과 반대 방향으로 3.7초어치 밀어 올린다.**

**그래도 오늘은 안 건드린다.** 빠르기와 플루트 세기를 같이 바꾸면 무엇 때문에 달라졌는지 못 가른다(`13` 문서). **먼저 빠르기만 바꾼 소리를 내고, 플루트가 앞선다고 들리면 세기를 그때 따로 만진다.** 다만 **이 표가 「그럴 것이다」를 미리 적어두므로, 그 판정이 나왔을 때 이유를 찾아 헤매지 않는다.**

### 플루트 재료 하나가 자리를 못 받는다

`WORDER` 26개 중 **마지막 `j` 하나**가 떨어진다. 종결부가 `… c b j j` 에서 `… c b j` 가 된다.

**둘이 같은 재료이므로 가락은 안 끊긴다.** 종지(프리지안 E♭→D)는 남는다.

## 3. 8악장 전환 — 지금은 이어지고, 고치면 뛴다

두 악장은 **세는 단위가 다르다.** 7악장은 부점4분(♩. = 8분음표 셋), 8악장은 2+2+3 그룹 맥박이다. 공통 단위인 **8분음표 하나의 길이**로 환산해야 비교가 된다.

| | 7악장 끝 | 8악장 첫머리 (P=88) | |
|---|---|---|---|
| 지금 (72까지 올린 뒤) | 0.278초 | 0.292초 | **5% 느려짐 — 사실상 이어진다** |
| **60 고정** | 0.333초 | 0.292초 | **14% 빨라짐 — 한 단계 뛴다** |

**72로 올려두었던 진짜 이유가 이것이다.** 8악장에 도착했을 때 발걸음이 그대로 이어지도록 맞춰져 있었다. `07` 19장은 「그녀가 다가올수록 조인다」만 적고 이 인수인계는 안 적었다.

**8악장은 안 건드린다.** 8악장 빠르기 계단(88 → 104 → 120)은 16마디·20마디로 끊겨 있고 그 숫자가 「4마디마다 주역이 바뀌는 것」의 배수여서 골라졌다. 첫 단계를 낮추면 계단과 주역 교대가 어긋나고 악장 끝이 잘린다.

**그러므로 전환은 7악장 쪽 끝에서 처리한다.** 오늘 먼저 **T0(전환에 손대지 않은 판)**을 낸다 — 정말 거슬리는지부터 들어봐야 뒤의 판이 의미가 있다.

## 4. 무엇이 나오면 멈추는가

- 8악장 이하가 **±0.3 dB** 를 넘게 움직이면 → `prev=LAST` 말고 다른 경로가 있는 것이다. 찾고 나서 진행
- 7악장 조성 밖 음이 **눈에 띄게 늘면** → 음을 안 바꿨으므로 있을 수 없다. 있으면 내 계산이 틀린 것
- 플루트 가락이 **끊겨 들리면** → 재료가 하나 빠진 것 이상의 일이 난 것이다. 멈추고 검수자에게 되돌려 묻는다
