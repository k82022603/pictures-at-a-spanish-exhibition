## 왜 틀렸나 — 악장 격리가 난수에는 있고 화성에는 없다

어제 `mark(seed=)`로 끊은 것은 **흔들림 난수**다. 그런데 성부 진행에는 별개의 실이 있다.

```
전곡화성.py:244   prev = LAST          ← 1악장이 0악장의 마지막 보이싱을 받는다
전곡화성.py:262   LAST = prev          ← 1악장의 마지막이 다음 LAST 가 된다
전곡화성.py:269   lay_chords(PROG2, ..., prev=LAST)   ← 2악장이 받는다
```

**0 → 1 → 2 악장으로 이어지는 사슬이다.** 프롬나드끼리 성부를 이어 붙이는 것은 설계다(2악장 = "두 번째 발소리"). 문제는 그 사슬이 **오늘 고친 악장 밖으로 변화를 실어 나른다**는 점이다.

## 그런데 사슬은 한 악장을 건너가고 죽는다

파형으로 악장별 차이를 쟀다.

| 악장 | 차이 RMS |
|---|---|
| 0 프롬나드 | **−20.3 dB** ← 오늘 고친 곳 |
| **1 마드리드** | **−28.4 dB** ← 사슬이 실어 나른 변화 |
| 2 변주 I | −79.7 |
| 3~9악장 | −78 ~ −85 |

2악장 이후의 −78~−85 dB는 **마스터 정규화의 잔물결**이지 실제 변화가 아니다. 1악장만 그 층에서 8 dB 넘게 벗어나 있다.

**1악장 48개 화음을 지나는 동안 성부 진행 최적화가 원래 자리로 수렴한다.** `voice_lead`가 매번 이전 보이싱에서 가장 덜 움직이는 배치를 고르므로, 출발점이 달라도 몇 화음 안에 같은 궤도로 빨려 들어간다. 그래서 2악장이 받는 `LAST`는 결국 같다.

**다만 앞으로의 1.4 작업에 규칙이 하나 생겼다.**
