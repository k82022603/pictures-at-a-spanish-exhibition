**검수자** — *"9:08~9:09 여기, 9:26 여기 낙차로 장난치는 것 싫다고."*

## 1. 무엇이 문제인가 — 실측

**드럼이 심벌 직전 2.1초 동안 완전히 사라진다.**

| 시각 | 전체 | 드럼 |
|---|---|---|
| 9:07.0 | −18.4 | −22.3 |
| 9:07.5 | −16.9 | **−32.5** |
| 9:08.0 | −15.0 | **−54.7** |
| 9:08.5 | −17.0 | **−99.0** ← 완전 무음 |
| **9:09.0** | **−13.6** | **−10.0** ← 심벌 |

**9:26 앞도 같은 모양이다.**

| 시각 | 전체 | 드럼 |
|---|---|---|
| 9:24.5 | −18.7 | **−52.7** |
| 9:25.5 | −17.3 | −17.4 |
| **9:26.0** | **−14.3** | −20.7 |

**내가 오늘 「공백을 메우지 않고 공백을 썼다」고 적은 것이 이것이다.** 4악장의 「비워야 크게 들린다」를 여기 그대로 옮겼는데, **9악장은 4악장이 아니다.** 4악장은 무에서 쌓아 올리는 악장이고 **9악장은 끝까지 밀고 가는 악장**이다.

> **검수자 말이 맞다** — 비웠다가 때리는 것은 **때리는 힘이 모자랄 때 쓰는 수법**이다. 힘이 있으면 비울 필요가 없다.

## 2. 무엇을 하나

### ① 침묵을 탐 롤로 바꾼다 (546.9 ~ 549.0)

**공백을 메우되 평평하게 메우지 않는다.** 굴러 들어가게 한다.

| | |
|---|---|
| 지금 | **2.1초 무음** → 심벌 |
| 바꾼 뒤 | **탐이 굴러 내려오며 세진다** → 심벌 |

**낙차가 아니라 밀고 들어가는 힘이 된다.** 롤은 「비우기」의 반대다 — 계속 치면서 커진다.

### ② 심벌을 훨씬 세게 (549.0)

| 무엇 | 지금 | 바꾼 뒤 |
|---|---|---|
| 크래시 | 0.92 (1장) | **1.00 · 두 장 겹침** (씨앗을 달리해 두껍게) |
| 킥 | 1.00 | **1.00 + 저역 탐** |
| 스네어 | 0.80 | **0.95 오픈** |
| 전체 게인 | ×0.72 | **×0.95** |

### ③ 9:26 진입의 골을 메운다 (563 ~ 566)

**9:24.5 의 드럼 −52.7 을 없앤다.** 2박 화음 구간에 드럼이 안 놓이는 것이 여기서도 같은 원인이다.

> **★ 566 이후는 안 건드린다.** 「컴파스가 566에서 멈추고 걸음만 남는다」는 서사이고, **거기에 드럼을 넣으면 F♯→F 해소가 흐려진다.** 골을 메우는 것은 **566 앞까지**다.
