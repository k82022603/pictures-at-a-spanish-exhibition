## 세션 3 — BL-24b 무그 필터 자기발진 (v1.10)

**타이밍 스파이크 먼저.** 비선형 라더는 벡터화 불가라 파이썬 샘플 루프가 된다. 추정치를 검증했다.

- 실측 처리량 **143만 샘플/초** (추정 50만보다 좋음)
- 전곡 렌더 추가분 **8.5초** (2배 오버샘플링 포함). 추정 30초~1분보다 나음 → 오버샘플링 넉넉히 채택

**옛 필터가 발진 못 한 이유가 구조였음을 실측으로 확정.**

| 검사 | `ladder_sweep` | `ladder_nl` |
|---|---|---|
| 입력 0 · res=1.0 | **RMS 0.00000000** | **RMS 0.190** |
| 임계 아래(res=0.5) | — | 0.000000 |
| 임계 전후 대비 | — | 131만 배 |
| 진폭 발산 | — | 없음 (최대 0.29) |

**음정 잡기 — 두 번 틀림**

| 단계 | 최대 오차 |
|---|---|
| 초기 (`1-exp` 근사) | 34센트 |
| 위상 조건 — 틀린 풀이 (0.5ω) | **138센트** |
| 위상 조건 — 바른 풀이 (1.5ω) | 41센트 |
| + 실측 보정표 | **3.9센트** |

되먹임 경로가 `0.5·(y4[n-1] + y4[n-2])`라 지연이 1.5샘플인데 0.5샘플로 셈했다.

**레벨 정합 — 한 번 틀림**

전곡 렌더 두 벌로 실측: `lead` 스템 −26.6 dB(옛) 대 −30.4 dB(새) = **3.8 dB 감소**. 1.549를 넣었더니 2.6 dB만 나옴 — `moog()`가 필터 뒤에 `tanh(y*1.6)`을 걸어 압축되기 때문. 대표 표본 48음으로 이분 탐색해 **`LEVEL_MATCH = 2.0151`** 확정.

**회귀 검증 (최종)**

| 지표 | v1.5 기록 | 최종 |
|---|---|---|
| 경직됨 | 0.941 | **0.941** |
| 프레즌스 | −10.9 dB | **−10.9 dB** |
| `lead` (페이더 전) | 옛 필터 −26.6 | **−26.5** |
| 악장별 RMS 10개 | 표 | **전부 일치** |
| 성부 진행 | 349개·3.93반음·병행 0 | **동일** |

**전곡 렌더 4회** — 신필터 / 옛필터 기준선 / `LEVEL_MATCH=1.549` / `LEVEL_MATCH=2.0151`.

**청취 판정** — `무그 자기발진 데모 - BL-24b.wav` (A 옛필터 0:00~5.2 · B 새필터 7.2~12.4 · C 비명 14.3~19.6). 검수 결과 **"구별 안 됨 → 통과"**.
