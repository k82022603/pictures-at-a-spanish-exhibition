### 블록 C — 실사와 기준선

`전곡화성.py`의 `lay_bass` 호출은 **다섯 곳**(141·164·205·304·432행 = 0·1·3·5·9악장). **4·6·7·8악장은 `D["bass"].put(rick(...))` 직접 배치**로 이미 손으로 짜여 있었다. BL-25 백로그 서술("알고리즘 생성이다")과 코드가 달랐다.

4악장: 컴파스 강세 `{0,3,6,8,10}`에만, 근음 `{0:43, 1:41, 2:39, 3:38}` = 안달루시아 종지 G–F–E♭–D. **사양은 이미 충족.** 죽은 코드 1줄 발견(271행, 다음 줄에서 덮어써짐).
6악장: 화음마다 근음+3음을 12씩 올려 병행. **주석은 "선율을 나눠 든다"인데 `MEL6`과 아무 관계 없음.**

기준선 확보 — 현재 wav와 스크립트를 스크래치패드에 백업하고, **미수정 코드로 직접 렌더**해 오늘의 기준을 만들었다(문서값을 믿지 않는다).
