# 브라우저 도구 비교 — Chrome 확장과 인앱 브라우저

Claude Code가 웹사이트를 조작하는 방법이 두 가지 있다. **무엇이 다르고, 내가 언제 있어야 하는가.**

---

## 1. 이 둘은 무엇인가

### Chrome 확장 (Claude in Chrome)

**내 Chrome을 빌려 쓴다.** Chrome 브라우저에 확장을 설치하면 Claude Code가 **내 Chrome 창을 원격 조작**한다. 내가 로그인해 둔 사이트를 그대로 쓸 수 있다. Chrome이 열려 있어야 한다.

### 인앱 브라우저

**Claude Code 안에 브라우저가 있다.** Claude Code 화면 안에 **별도의 브라우저 창**이 열린다. 내 Chrome과 완전히 분리돼 있다. 로그인도 쿠키도 없는 새 브라우저다.

---

## 2. 나란히 비교

| 항목 | Chrome 확장 | 인앱 브라우저 |
|---|---|---|
| **설치** | 확장 설치 + Claude 계정 연결 | **없음** — 바로 열림 |
| **로그인 상태** | **유지** — 이미 로그인한 사이트 그대로 | **새로** — 처음부터 로그인해야 |
| **Chrome 필요** | **필요** — Chrome이 열려 있어야 | **불필요** — Claude Code만 있으면 |
| **파일 올리기** | 가능 | 가능 |
| **화면 확인** | 내 Chrome에서 직접 보인다 | Claude Code 옆 패널에 보인다 |
| **세션 지속** | Chrome이 켜져 있는 한 유지 | 이 대화가 끝나면 사라진다 |
| **다른 탭 영향** | **있음** — 내 탭 목록에 섞인다 | **없음** — 완전히 분리 |
| **속도** | 확장 연결 후에는 빠름 | 바로 시작, 로그인 시간만큼 |

---

## 3. 내가 항상 함께 있어야 하나

**아니다. 다만 두 번은 있어야 한다.** 어느 방법이든 Claude가 혼자 못 하는 것이 두 가지 있다 — **비밀번호 입력**과 **로봇 확인(CAPTCHA)**. 이 두 순간만 지나면 나머지는 Claude가 혼자 한다.

### Suno 1부를 뽑을 때 내가 할 일

| 단계 | 누가 하나 | 비고 |
|---|---|---|
| ① Suno 로그인 | **내가 한다** | 두 방법 모두. 비밀번호는 Claude가 못 친다 |
| ② 파일 올리기 · 설정 입력 · 가사 붙여넣기 | **Claude** | |
| ③ 생성 버튼 누르기 | **확인 필요** | 돌이킬 수 없는 동작이라 Claude가 먼저 물어본다 |
| ④ Suno가 만드는 동안 기다리기 | **자리 비워도 됨** | |
| ⑤ 결과 내려받기 | **Claude** | |
| ⑥ 판정 (듣고 판단하기) | **내가 한다** | 검수자의 귀 |

**정리하면 — 처음에 로그인 한 번, 끝에 듣고 판단 한 번.** 가운데는 Claude가 한다. ③번은 Suno 크레딧을 쓰는 동작이라 Claude가 알아서 누르기 전에 물어본다.

> **Chrome 확장을 쓰면 로그인도 필요 없나?**
>
> Chrome에서 이미 Suno에 로그인해 둔 상태라면 **그렇다 — ①도 건너뛴다.** 이것이 Chrome 확장의 가장 큰 장점이다. 인앱 브라우저는 매번 새 브라우저이므로 매번 로그인해야 한다.

---

## 4. 이번 Suno 작업에는 어느 것이 맞나

1부만 뽑는 것이 아니라 **2·3·4부까지 네 번** 뽑아야 한다. 그리고 판마다 **두세 판씩** 뽑으니 총 8~12회다.

| | Chrome 확장 | 인앱 브라우저 |
|---|---|---|
| 초기 셋업 | **10분** — 설치 + 연결 | **0분** |
| 로그인 횟수 | **0번** (이미 돼 있으면) | **세션마다 1번** |
| 이후 재사용 | **영구** — 다음 세션에서도 | 이 대화에서만 |
| 내 개입 최소 | **③⑥만** | ①③⑥ |

### 결론

**Chrome 확장을 한 번 깔아두는 것이 낫다.** 초기 10분을 쓰면 이번뿐 아니라 앞으로 웹사이트를 쓸 일이 있을 때마다 로그인 없이 바로 들어간다. Suno를 8~12회 돌려야 하는 지금, 매번 로그인하는 것보다 한 번 설치하는 것이 빠르다.

- **지금 Chrome에서 Suno에 로그인돼 있다면** — 확장만 설치하면 바로 시작이다
- **로그인이 안 돼 있다면** — 인앱 브라우저로 시작하고, 나중에 확장을 깔아도 늦지 않다

---

## 5. Chrome 확장 설치 (한 번만)

1. Chrome에서 아래 주소를 연다
   - `https://chromewebstore.google.com/detail/fcoeoabgfenejglbffodgkkbkcdhcgfn`
   - 또는 Chrome 웹스토어에서 **"Claude in Chrome"** 검색
2. 확장을 설치한다
3. Chrome 오른쪽 위 퍼즐 아이콘 → Claude 확장 → 사이드패널이 열린다
4. 사이드패널에서 **이 앱(Claude Code)과 같은 계정**으로 로그인한다
5. **"연결됐다"고 말해주면** — Claude Code에서 다시 시도한다

## 별첨. 내가 직접 하는 것과 Claude에게 시키는 것

위 1~5절은 **Claude가 브라우저를 조작하는 두 방법**의 비교다. 여기서는 한 걸음 더 나간다 — **애초에 Claude에게 시킬 것인가, 내가 직접 Suno를 쓸 것인가.**

### 세 가지 방법이 있다

| | ⓐ 내가 직접 | ⓑ Claude가 대신 | ⓒ 섞어 쓰기 |
|---|---|---|---|
| **설정 입력** | 입력지를 보고 내가 넣는다 | Claude가 넣는다 | Claude가 넣는다 |
| **생성 버튼** | 내가 누른다 | Claude가 물어보고 누른다 | Claude가 물어보고 누른다 |
| **결과 듣기** | Suno 화면에서 바로 듣는다 | 내려받은 파일로 듣는다 | Suno에서 먼저 듣고 고른다 |
| **설정 조절** | 들으면서 바로 바꿔본다 | Claude에게 말로 시킨다 | 내가 직접 바꾼다 |
| **파일 정리** | 내가 이름 붙여 폴더에 넣는다 | Claude가 한다 | Claude가 한다 |
| **판정 기록** | 내가 적거나 Claude에게 시킨다 | Claude가 초안을 쓴다 | Claude가 초안을 쓴다 |

### 무엇이 다른가 — 속도가 아니라 감각이다

**Claude에게 시키면 빠르다.** 입력지를 그대로 넣고, 파일 이름을 붙이고, 폴더에 넣는 반복 작업을 안 해도 된다. 설정을 틀릴 일도 없다.

**그런데 Suno의 감각은 직접 만져봐야 는다.** `Audio Influence`를 70에서 80으로 올리면 소리가 어떻게 달라지는지, `Weirdness`가 뭘 하는 건지, 가사 칸의 `[Instrumental]` 태그가 정말 먹히는지 — 이런 것은 **버튼을 눌러보고 결과를 들어봐야** 몸에 남는다. Claude에게 시키면 결과물은 받지만 그 감각은 안 는다.

### 경험치를 어디에 올릴 것인가

솔직히 말하면 **둘 다 올려야 하는데, 지금은 하나를 고를 때다.**

| | Suno 경험치를 올리면 | Claude Code 경험치를 올리면 |
|---|---|---|
| **지금 얻는 것** | 설정 감각. 들으면서 바로 조절하는 속도 | 반복 작업 위임. 판정에만 집중할 시간 |
| **나중에 남는 것** | Claude 없이도 Suno를 쓸 수 있다 | Suno 말고 다른 웹 도구에도 같은 방식을 쓴다 |
| **이 프로젝트에서** | 9/3까지 8~12회 뽑는 동안 직접 쓴다 | 뽑기는 맡기고 판정과 설계에 시간을 쓴다 |
| **리스크** | 반복 작업에 시간을 쓴다 | Suno UI가 바뀌면 Claude가 헤맨다 |

### 추천: 1부는 직접, 2부부터 맡긴다

**1부는 어차피 설계의 전제를 확인하는 판이다.** 통과선 다섯을 직접 보면서 "Suno가 무엇을 잘하고 무엇을 못하는지"를 손으로 익힌다. 설정을 바꿔가며 두세 판 돌리면 `Audio Influence`와 `Duration`이 무엇을 하는지 몸으로 안다.

**그 감각이 생긴 뒤에 2·3·4부는 Claude에게 시킨다.** 그때는 "70을 80으로 올려봐"라고 말할 때 그 말이 무엇을 뜻하는지 아는 상태다. Claude가 내려받은 결과를 듣고 판정하는 데 집중하면 된다.

> **Suno는 9월 3일 약관 변경 뒤에 안 쓸 수도 있다.** 그러니 Suno 전문가가 될 필요는 없다. 하지만 **"이 도구가 무엇을 하는 물건인지"는 한 번은 직접 만져봐야 안다** — 그래야 결과를 판정할 때 "이건 설정 문제다"와 "이건 Suno의 한계다"를 가를 수 있다.
