## 4. 함께 정하실 것 — 9:16 의 「두 목소리」

`05` 9.31.4절이 **주제 A 를 3도 위로 올리면 그녀의 선율(주제 B)이 그대로 나온다**는
것을 실증했고, 9:16 은 그 둘을 겹치는 자리입니다. 그런데 **위 목소리의 최고음이
A5** 입니다.

```
아래 목소리   G4  F4  B♭4 C5  F5  D5  C5  F5  D5  B♭4 C5    ← 최고 F5
위  목소리   B♭4 A4  D5  E♭5 A5  F5  E♭5 A5  F5  D5  E♭5   ← 최고 A5
```

**A5 는 남성에게 F5 와 차원이 다른 자리입니다.** 목소리를 고르는 기준 자체가 바뀝니다.

**이번에는 아래 목소리 네 줄만 만듭니다.** 위 목소리는 ⓐ 같은 목소리를 겹칠지
ⓑ 무그(그녀)가 대신할지 — **소리를 들어보고 정하는 것이 맞습니다.**
