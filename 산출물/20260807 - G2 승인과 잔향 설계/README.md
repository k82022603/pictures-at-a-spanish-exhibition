## 왜 승인 음원과 기준선이 다른 파일인가

G2 판정 대상은 **렌더 재현성을 고치기 전**에 만들었다. 그날 오후 BL-30에서 씨앗 없는 전역 난수를 끊었고, 그래서 지표는 전부 같지만 파형이 다르다. **앞으로의 기준선은 `v2.1 재현 가능 렌더` 쪽이다** — 다시 만들 수 있는 파일이어야 하니까.

다만 지금은 둘 다 다시 만들 수 없다. 코드가 없다.
