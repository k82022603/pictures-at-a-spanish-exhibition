> Suno 에는 악보를 넣는 칸이 없습니다. **「이 음을 불러라」를 소리로 알려주는 수밖에 없습니다.**
> 우리가 받을 것은 **Suno 의 목소리**이고, 이 로봇 소리는 거기서 버려집니다.

## 1. 여덟 단계

### ① 들어가서 `Create` 화면 → **`Advanced`** 탭

<https://suno.com> · 어제 결제하신 **Pro** 계정 그대로입니다.

### ② **`+ Audio`** 를 눌러 파일을 올린다

**`+ Voice` 가 아닙니다.** 그건 검수자님 목소리를 올리는 칸입니다.

- 파일 — **`Suno 재료 A - 목소리 앞.wav`**
- 「무슨 소리인가」를 물으면 — **`Full Song`**
- 설명 칸 — **비워 둡니다**

### ③ ★ **`Cover` 로 잡혀 있는 것을 반드시 바꾼다**

올리고 나면 **저절로 `Cover` 로 설정됩니다.** 그대로 두면 **곡을 통째로 다시 만듭니다.**

**`Audio` 오른쪽의 `Cover ⌄`** 를 누르고 → **`EDIT`** 묶음 안의 → **`Edit vocals`**

화면에 *"Add or replace the song's vocal performance"* 라고 뜨면 맞게 고른 것입니다.

### ④ `Lyrics` 칸을 **전부 지우고** 아래를 붙여넣는다

**Suno 가 제멋대로 채워 넣습니다. 지우고 넣으셔야 합니다.**

```
[Verse]
I count out every step under my own feet

[Verse]
Now we walk, two of us, never in one step

[Verse]
Now the light in the old picture holds you too

[Verse]
Looking back, you were here always in my step
```

### ⑤ `Styles` 칸도 **전부 지우고** 아래를 붙여넣는다

```
1970s British progressive rock male lead vocal.
Warm, straight tone with almost no vibrato.
Understated and conversational — speaking more than singing.
Chest voice, not belting. Soft consonant attacks.
Slightly behind the beat, unhurried.
Range F4 to F5. Dry, close, no heavy reverb.
```

**`Exclude styles` 칸**에는 이것을 넣습니다.

```
autotune, modern pop production, heavy vibrato, operatic,
female vocals, backing harmonies, rap, shouting, belting
```

### ⑥ `More Options` — **어제와 똑같이** 맞춘다

| 항목 | **넣을 값** | 기본값이 다르니 주의 |
|---|---|---|
| `Lyrics` | **`Write`** | |
| `Vocal Gender` | **`Male`** | **안 고르면 여자 목소리가 나올 수 있습니다** |
| `Weirdness` | **15%** | 기본 50% |
| `Style Influence` | **75%** | 기본 50% |
| **`Audio Influence`** | **80%** | **★ 기본이 25% 입니다. 반드시 올리셔야 합니다** |
| `Duration` | **`Auto`** | |
| `Song Title` | **비움** | |

### ⑦ `Create` 를 **두 번** 누른다

**한 번 누르면 두 곡이 나옵니다.** 두 번 누르면 **네 곡**입니다.

**설정은 바꾸지 않고 그대로 두 번**입니다 — 같은 조건에서 여러 번 뽑는 것이지, 조건을 바꾸는 게 아닙니다. **Suno 는 같은 설정에서도 매번 다르게 부릅니다.**

### ⑧ **네 곡을 전부 내려받는다**

**마음에 안 드는 것도 받으십시오.** Suno 는 같은 것을 두 번 만들지 못합니다 — **안 받으면 그 소리는 사라집니다.**

받으신 파일은 이 폴더 안의 **`Suno-20260820`** 폴더에 넣어 주시면 됩니다.

**목소리만 따로 받는 기능이 보이면 그것도 받아 주십시오.** 없으면 통합본만 받으셔도 됩니다 — 이쪽에서 반주를 걷어낼 수 있습니다.
