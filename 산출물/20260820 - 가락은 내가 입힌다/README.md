## 4. 실패한 것 — 가락 입히기 여덟 판

**전부 남겼습니다**(R11). **왜 실패했는지가 이 파일들에 있습니다.**

| 파일 | 방식 | 검수 |
|---|---|---|
| `가락 입힌 것 - 한 줄.*` | 첫 판 | **실패** — 안 들림 |
| `가락 입힌 것 - 세 줄 (Suno -04).*` | 음절 붙이기 성공 | **실패** — −29.3 dB |
| `가락 입힌 것 - 세 줄 크게 (Suno -04).*` | 볼륨 키움 | **실패** |
| `들어보세요 - 가락 입힌 것.*` | 초저역 제거 | **실패** |
| `들어보세요 - 가락 입힌 것 (새 방식).*` | 속도로 음 옮기기 | **실패** |
| `들어보세요 - 가락 입힌 것 (세번째 방식).*` | 늘이는 처리 없이 | **실패** |
| `A와 B - 번갈아 듣기*.mp3` | 원본과 번갈아 견주기 | **판정 도구** — *"A는 크고 B는 작게"* |
| **`9악장에 얹은 것.*`** | **반주 위에 얹어 판정** | **★ 여기서 「잡음」 판정** |
| `시험 - 삐 소리 뒤에 노래.*` | 재생 경로 확인용 | 삐는 들리고 노래는 안 들림 |
