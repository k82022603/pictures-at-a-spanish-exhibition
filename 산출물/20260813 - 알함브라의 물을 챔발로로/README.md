# 20260813 — 7악장에 선율이 들어왔다

**프로젝트 버전 v4.19 → v4.21** · 시작 기준선 **v4.19**

> **폴더 이름이 실제와 다릅니다.** 아침에 「챔발로로」 시작했는데 **챔발로는 기각**됐고 하루가 **플루트 선율**로 끝났습니다. **폴더 이름은 안 바꿉니다** — 그날 무엇을 하려 했는지도 기록입니다.

**오늘 렌더를 열두 번 했고 채택된 것은 하나입니다.** 미채택도 전부 남깁니다(R11) — **무엇과 비교해서 저것을 골랐는가가 판정의 절반**입니다.

**오늘부터 발췌는 24비트, 전곡은 32비트입니다**(검수자 판정). **발췌도 `납품.py` 가 굽습니다** — 어제까지 손으로 `ffmpeg` 을 부르던 것이 32비트 전곡만 안 열리던 사고의 원인이었습니다.

## 3. 무엇이 들리나

### 가장 쉬운 확인법

**5:25부터 12초.** 플루트가 왼쪽에서 노래하고, 그녀(신디사이저)는 오른쪽에서 8초마다 답합니다.

### 플루트가 우는 시각 — 음원에서 쟀습니다. 26번

| | |
|---|---|
| 5:25 · 5:29 · 5:33 · 5:37 · 5:41 · 5:45 · 5:49 · 5:53 · 5:57 · 6:01 · 6:05 · 6:09 · 6:13 | **4초 간격** |
| 6:17 · 6:20 · 6:23 · 6:27 · 6:30 · 6:33 · 6:37 · 6:40 · 6:43 · 6:47 · 6:50 · 6:53 · 6:57 | **3.3초 간격으로 좁아집니다** |

**한 번에 평균 2.9초** 울고 쉽니다.

### 무슨 소리인가

**화음이 바뀌어도 플루트가 소리를 안 놓습니다.** 앞 화음의 음이 다음 화음 위에 그대로 걸려 **긁히는 자리**가 생기고, 그 긁힘이 풀리지 않고 다음으로 넘어갑니다. **끝도 D 가 아니라 E♭ 에서 멈춰 열려 있습니다.**

### 세 목소리의 자리

| | 크기 | |
|---|---|---|
| 물소리 (피아노) | −6.9 dB | 가장 앞. 100초 내내 |
| **그녀 (무그)** | **−17.1 dB** | **주인공** |
| **플루트** | **−19.0 dB** | 그녀보다 1.9 아래 |

**`I` 판에서는 플루트가 그녀보다 4.8 dB 위에 있었습니다.** 걸리는 음(29 → 26)은 두고 **길이와 세기만 되돌린 것**이 채택판입니다.
