| | 결론 | 왜 |
|---|---|---|
| **합성 콘텐츠 표시** | **켠다** | 정책이 **「AI generated music」** 과 **「AI generated extra footage of a real place」** 를 공개 대상으로 명시합니다. **우리는 둘 다** — 음원 전체가 Suno 생성이고 **그녀 샷은 실제 장소에 없던 인물을 넣는 것**입니다 |

**사진 업스케일은 안 걸립니다** — 정책이 「video sharpening or upscaling」을 공개 불필요로 둡니다.

**설명란 문안 셋**(원곡 출처 · 편곡 주체 · 생성 도구)은 `18` 8.3절에 한국어·영어로 있습니다.
