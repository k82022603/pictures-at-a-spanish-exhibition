## 2. 안 채택된 것 — **지우지 않는다** (R11)

**「무엇과 비교해서 저것을 골랐는가」가 판정의 절반이다.**

| 폴더 | 무엇 | 왜 안 됐나 |
|---|---|---|
| `*.png` (맨 위 여섯) | **첫 판 — 검은 옷** | **`03` 3.2절이 「붉은 만톤」으로 정해 뒀다.** 내 프롬프트가 `dark shawl` 이었다. 검수자 — *"새까만 옷?"* |
| `붉은 만톤/` | 붉은 만톤 첫 시험 (세고비아 1장) | 색은 맞았으나 **모델이 그녀를 가운데로 옮기고 4배 키웠다** |
| `붉은 만톤 여섯/` · `… - 오려 붙인 것/` | **칸만 잘라 보낸 판** | 자리·크기는 맞았으나 **화면의 0.3% 라 안 보였다.** 검수자 — *"만톤 거의 안보임"* |
