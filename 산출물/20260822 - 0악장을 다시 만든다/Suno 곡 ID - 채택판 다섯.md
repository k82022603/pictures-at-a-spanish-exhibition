# Suno 곡 ID — 채택판 다섯

**2026-08-22 확보.** 내려받은 파일의 메타데이터(`comment` 태그)에 **Suno 곡 ID 가 박혀 있다.**

```bash
ffprobe -v error -show_entries format_tags=comment -of default=nw=1:nk=1 "파일.mp3"
# → made with suno; created=2026-08-21T20:43:03Z; id=6a2167ae-...
```

---

## 왜 이것이 필요한가

**Suno 안에서 그 곡을 다시 열려면 ID 가 있어야 한다.**

라이브러리에는 같은 이름(`mov0-planA`)의 곡이 넷씩 있고 **길이도 0:50 으로 같아서 눈으로는 못 가린다.**
2026-08-22 에 0악장 Extend 를 하려다 **어느 것이 채택판 Suno-02 인지 짚을 수 없었고**,
파일 메타데이터에서 ID 를 읽어 해결했다.

> **`https://suno.com/song/<ID>` 로 바로 간다.**
