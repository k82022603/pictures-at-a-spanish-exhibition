# 잘못 만든 것 — 16비트판

**2026-08-22.** `납품.py` 가 경고를 찍어 발견했다.

> ⚠ 마스터가 **s16** 이다. 32비트로 못 간다

**내 `쓰기()` 함수가 `np.int16` 으로 저장하고 있었다.**

## 무엇이 문제였나

| | 비트 |
|---|---|
| Suno 가 준 원본 | **16비트** |
| 이 폴더의 것들 | 16비트 |
| 어제 만든 전곡 A | **float (32비트)** |

**원본이 16비트라 정보를 깎은 것은 아니다.** 다만 —

* **우리가 더한 것**(잔향 꼬리 · 크로스페이드 · 페이드)은 계산이 더 정밀한데 **16비트로 양자화됐다.**
  꼬리 끝이 **−85 dB** 인데 16비트 잡음 바닥이 **−96 dB** 라 **여유가 11 dB 뿐**이다
* **전곡 A 는 float 인데 E 만 16비트면 앞뒤가 안 맞는다**

## 왜 안 지우나

**R11 — 산출물 파일을 지우지 않는다.** 그리고 이 폴더 자체가 기록이다.
**「32비트 FLAC 이 무손실 100% 일치」라고 찍혀도 그 안이 16비트일 수 있다**는 것을
보여준다. `납품.py` 는 그것을 **경고로 찍었고, 나는 처음에 그것을 지나쳤다.**
