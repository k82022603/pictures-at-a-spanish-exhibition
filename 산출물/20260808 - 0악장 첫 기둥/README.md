## 두 판의 관계

**0:38.5까지 같은 소리다**(차이 −59 dB = 잡음 층). 그 뒤에서만 −21.0 dB로 갈린다. 판정 변수를 하나로 두기 위해 6회차 `lay_line`을 0악장 코드의 **맨 끝**에 붙였다 — 그러면 앞의 난수 소비가 그대로다.

**A판을 지우지 않는다.** 채택되지 않았어도 판정의 근거이고, "무엇과 비교해서 B를 골랐는가"가 여기 있다.

## 두 판 공통

화성 보이싱 상한을 `50~70`에서 `53~65`로 낮췄다. 나중에 목소리(주제 A = MIDI 65~77)가 앉을 자리를 비우는 것이고, 지금은 노래가 없으므로 **그 자리가 빈 채로** 들린다.
