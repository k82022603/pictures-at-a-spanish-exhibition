## 4. ★ 드러난 것 둘

### 4.1 **`Audio Influence` 가 지렛대가 아니다**

| | 화성·시간 평균 | **같은 값 안에서의 차이** |
|---|---|---|
| 70% | 0.590 | **0.123** |
| 85% | 0.633 | **0.145** |
| 95% | 0.557 | **0.147** |

**값을 올려도 안 올라간다.** 95% 가 70% 보다 낮다.
그리고 **같은 값으로 두 번 뽑은 것들끼리의 차이(0.12~0.15)가
값을 25%p 움직였을 때의 차이(0.076)보다 크다.**

> **즉 판마다 다른 것은 설정이 아니라 운이다.**
> **더 쓸어봐야 같은 자리를 맴돈다.**

### 4.2 **강약이 통째로 안 따라온다**

**화성은 절반쯤 따라오는데(0.48~0.71) 강약은 거의 0 이다**(−0.07~0.25).

> **★ 처음에 「부풀어 오르는 모양이 없다」고 적었다가 고쳤다.**
> 재보니 **원곡 이 발췌 자체가 안 부푼다** — 앞 10초 −14.1 dB, 끝 10초 −13.5 dB.
> **9악장의 마지막 55초라 이미 총주 안에 들어와 있다.**
> 오케스트라판들도 −0.3 ~ +1.9 dB 로 같은 자리다.

**그러니 「강약 0」이 뜻하는 것은 큰 활이 아니라 순간순간의 밀고 당김이다.**
어느 박에서 조이고 어느 박에서 놓는가 — **악구를 부는 방식이 우리 것과 무관하다.**

> **Suno `Cover` 는 「받아 적기」가 아니라 「듣고 새로 연주하기」다.**
> 우리가 원한 것은 앞엣것인데 도구가 하는 것은 뒤엣것이다.
