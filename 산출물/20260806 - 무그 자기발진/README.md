옛 무그 필터는 되먹임이 없어 자기발진이 원리적으로 불가능했다(입력 0 · res=1.0에서 RMS 0.00000000 실측). 되먹임 라더 `ladder_nl`을 새로 만들어 발진 음정 오차 3.9센트를 얻었다.

**비명(`scream`)은 곡에 아직 한 번도 들어가 있지 않다.** 배치는 WBS 1.4 소관이고, 1.4.8(9악장)에서 무그 벨팅과 같은 자리에서 정한다.

실측은 `05` 9.10절 · 회고는 없음(사고가 아니라 정상 작업이었다).
