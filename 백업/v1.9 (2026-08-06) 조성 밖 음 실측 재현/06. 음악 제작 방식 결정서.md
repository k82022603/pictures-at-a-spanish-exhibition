## 1. 결정

**자체 합성기(numpy/scipy)로 계속 간다.** v1.3이 기준선이다.

결정을 뒷받침한 사실 하나가 있다. 검수자가 **1970년대 프로그레시브 신디사이저 소리를 개인적으로 좋아한다**고 밝혔다. 이 한 문장이 판정을 뒤집었다. AI 음악 생성기는 현대적이고 매끈한 프로덕션으로 수렴하는데, 그것은 원하는 방향의 **반대**다.

무그의 거친 필터, 해먼드의 레슬리 왜곡, 테이프 새추레이션 — 그 시대 소리의 정체는 "덜 다듬어진 것"이다. AI 생성기는 그걸 깎아낸다.

---

## 2. 왜 이 판정이 필요했나

v1.2 데모에 대한 지적이 발단이었다.

> "주제 B — 솔직히 좋다라는 느낌을 받지 못함. 조잡하다? 1970년대 수준 미디(신디사이저) 음악?"

이 지적에는 세 원인이 섞여 있었고, 분리해보니 해결 주체가 달랐다.

| 원인 | 실제 문제 | 해결 |
|---|---|---|
| **편곡·연주** | 12박 컴파스에 라스게아도·팔마스·카혼·오르간·무그를 한꺼번에 넣어 선율이 묻혔다. "그녀가 태어나는 순간"인데 처음부터 총주였다 | **v1.3에서 고쳤다.** 밀도를 쌓아 올리는 구조로 재구성 |
| **베이스** | "독립 대선율"이라 문서에 써놓고 실제로는 근음을 피한 저음 반주였다. 악기도 톱니파 신스였다 | **v1.3에서 고쳤다.** 리켄배커 물리 모델 + 8분음표 대선율 |
| **음색 사실감** | 모든 음이 같은 세기·타이밍·필터 곡선 | **절반 고쳤다.** 연주 흔들림 도입. 나머지는 합성기의 천장 |

셋째 항목이 BL-06의 대상이었다. 그런데 판정 과정에서 **애초에 사실감이 목표가 아니었다**는 것이 드러났다.

## 3. 두 방식의 차이

Suno는 `AceDataCloud/SunoMCP`(도구 28개)을 통해 Claude.ai에 OAuth로 연결할 수 있다. 실물을 확인했으므로 가정이 아니라 실제 선택지였다.

| 축 | 자체 합성 | Suno (chirp-v5-5) |
|---|---|---|
| **구조 통제** | 음 하나까지 완전 | 프롬프트로 유도만. `upload_cover`로 일부 유지 가능 |
| **길이** | 정확히 580.0초 | **최대 8분.** 9:40은 `extend`·`concat` 필요 |
| **타임코드 정밀도** | 밀리초 단위, 결정적 | 불가. `get_timing`은 자막용 |
| **두 주제 구조** | 설계대로 심는다 | 모델이 이해할 수 없는 개념 |
| **서사 밀도 설계** | 구간별로 통제 | 통제 불가 |
| **재현성** | 시드 고정 시 **완전 결정적** | 매 생성마다 다름 |
| **수정 반복** | 스크립트 한 줄, 80초 렌더 | 재생성마다 비용, 결과가 바뀜 |
| **검증 가능성** | 크로마·스펙트럼·온셋 실측 | 결과물 청취만 |
| 음색 사실감 | 낮음 | 높음 |
| 프로덕션 광택 | 낮음 | 높음 |
| **1970s 프로그레시브 질감** | **근접** | 현대적으로 수렴 |
| 비용 | 0 | 리셀러 종량제 |
| **저작권** | **전액 보유** | 리셀러 약관 확인 필요 |
| 외부 의존 | 없음 | API 서비스 지속성 리스크 |
| 보컬 | 불가 | 가능 (다만 그녀는 가사를 부르지 않는다) |

## 4. 이 프로젝트에 결정적인 네 가지

일반적인 비교가 아니라 **이 프로젝트의 구조** 때문에 결정적인 항목들이다.

### 4.1 타임코드 정밀도

기획서 4.3의 편집 문법은 **컷을 음악의 마디·박 그리드에 맞춰 자르는 것**이다. 30초 데모 검증에서 온그리드 어택 에너지가 오프그리드의 2.4배로 확인됐고, 이것이 영상과 음악을 묶는 유일한 장치다.

자체 합성은 마디 위치를 밀리초로 안다. Suno 결과물은 마디 위치를 **추정해야** 하고, 미세한 템포 흔들림이 있으면 9분 40초 끝에서는 컷이 크게 어긋난다.

**이 한 가지만으로도 자체 합성이 유리하다.**

### 4.2 9분 40초 단일 악곡

`chirp-v5-5`가 최대 8분이다. 9:40을 만들려면 나눠 생성해 이어붙여야 하는데, 접합부의 조성·템포·음색이 맞지 않을 위험이 있다. 우리 곡은 프롬나드 주제가 전체를 관통하는 구조라 접합부 불일치가 치명적이다.

### 4.3 게이트 반복과 재현성

이 프로젝트는 G1~G7 검수 게이트를 거치며 **같은 것을 조금씩 고쳐 다시 듣는** 방식으로 진행된다. 실제로 v1.1 → v1.2 → v1.3에서 그렇게 했다.

자체 합성은 시드를 고정하면 결정적이다. "현악만 10 dB 줄이고 나머지는 그대로"가 가능하다. Suno는 재생성마다 다른 곡이 나오므로 **A/B 비교가 성립하지 않는다.** 이 프로젝트의 작업 방식과 맞지 않는다.

### 4.4 저작권

유튜브 공개가 목표다. 기획서 2.2에서 선율 인용을 퍼블릭 도메인 무소르그스키로만 한정한 것도 이 때문이다.

자체 합성 음원은 저작권이 전적으로 이 프로젝트에 귀속된다. AceDataCloud는 **Suno 공식이 아닌 유료 리셀러**이므로, 생성 결과의 상용 권리가 Suno 본가 구독과 어떻게 다른지 별도 확인이 필요하다. 애써 정리한 권리 구조에 불확실성을 들여올 이유가 없다.

## 5. 자체 합성의 제약 — 포기하는 것

정직하게 적어둔다. 이 결정으로 잃는 것들이다.

| 제약 | 내용 | 완화 가능성 |
|---|---|---|
| **연주 아티큘레이션** | 레가토·스타카토·포르타멘토의 미묘한 단계, 연주자의 프레이징 호흡 | 부분적. 음마다 파라미터를 흔들 수 있지만 진짜 연주의 의도는 못 만든다 |
| **악기 간 상호작용** | 실제 앙상블에서 연주자들이 서로 듣고 맞추는 것 | 불가 |
| **녹음 공간의 질감** | 실제 스튜디오의 초기 반사, 마이크 특성 | 부분적. 합성 리버브로 흉내 |
| **보컬** | 사람 목소리 | 불가. 그래서 7악장 보칼리즈는 무그로 대체하거나 직접 녹음 |
| **현악의 사실감** | 합성 난도가 가장 높은 악기. 지금도 배경 베드로 쓰는 이유 | 제한적. 그래서 v1.2에서 −10.1 dB로 내렸다 |
| **프로덕션 광택** | 현대적 믹스의 매끈함 | 애초에 목표가 아니다 |

가장 아픈 것은 **현악**이다. 〈Mother Russia〉의 편성 기준이 현악 주도인데, 우리 현악은 앞에 나설 수준이 아니다. v1.2에서 현악을 줄이고 선율을 건반에 넘긴 것은 미학적 선택이기도 했지만 **한계를 인정한 결과**이기도 했다.

기획서 3.4의 **6악장 론다는 "광활한 현악 아다지오"**로 설계되어 있다. 이 악장이 이 제약의 시험대가 된다. BL-23으로 등록되어 있다.

## 6. Suno의 제약

Suno를 택했다면 만났을 문제들이다. 기록으로 남긴다.

| 제약 | 내용 |
|---|---|
| 8분 상한 | 9:40 단일 악곡 불가 |
| 정밀 타임코드 없음 | 영상 편집 그리드와 결합 불가 |
| 비결정적 | 게이트 반복 방식과 충돌 |
| 구조 통제 불가 | 두 주제·서사 밀도·악장별 편성 변화를 지시할 수 없다 |
| 공식 API 없음 | 서드파티 리셀러 경유. 서비스 지속성 리스크 |
| 권리 불확실 | 리셀러 경유 생성물의 상용 권리 별도 확인 필요 |
| 비용 누적 | 게이트마다 재생성하면 비용이 계속 발생 |
| **장르 수렴** | 1970년대 프로그레시브를 지시해도 현대적 프로덕션으로 수렴 |

마지막 항목이 이 프로젝트에서는 제약이 아니라 **부적합**이다.

## 7. 천장을 밀어올리는 방법

자체 합성으로 계속 간다면 남은 개선 여지는 이렇다. v1.3에서 어디까지 했는지 함께 적는다.

| 방법 | 상태 |
|---|---|
| 물리 모델 도입 (Karplus-Strong) | **완료** — 나일론 기타, 리켄배커 베이스 |
| 연주 흔들림 (타이밍 ±11ms, 세기 ±14%) | **완료** — v1.3 |
| 음마다 필터 곡선 변화 | **완료** — 무그 컷오프·레조넌스 랜덤화 |
| 편곡 밀도 설계 | **완료** — 주제 B를 층으로 쌓음 |
| **테이프 새추레이션** | 미착수. 1970년대 질감의 큰 부분 |
| **아날로그 콘솔 왜곡** | 미착수 |
| **레슬리 로터리 정교화** | 부분. 현재는 진폭 트레몰로 수준 |
| **무그 필터의 자기발진** | 미착수. ELP 특유의 비명 소리 |
| 프레이즈 단위 다이내믹 | 미착수. 지금은 음 단위 흔들림뿐 |
| 악장별 믹스 밸런스 | 미착수. Phase 1.5 예정 |

**미착수 항목 대부분이 "1970년대 질감"을 강화하는 방향이다.** 테이프 새추레이션과 무그 자기발진은 원하시는 소리에 직접 기여한다. AI 도구로 갔다면 이 방향으로는 갈 수 없었다.

## 8. 재검토 조건

이 결정을 되돌릴 조건을 미리 정한다. 감정이 아니라 기준으로 판단하기 위해서다.

| 조건 | 시점 | 조치 |
|---|---|---|
| G2 데모 승인이 **두 번 반려**되고, 원인이 편곡이 아니라 음색으로 특정될 때 | Phase 1 | BL-06 재개 |
| 6악장 론다의 현악이 끝내 설계를 감당하지 못할 때 | 1.4.5 작곡 시 | 그 악장만 부분 대안 검토 (BL-23) |
| 7악장 보칼리즈를 사람 목소리로 가야 한다고 판단될 때 | BL-05 결정 시 | 보컬만 외부 도구. 반주는 자체 유지 |
| 최종 마스터링에서 음질이 납품 기준에 미달할 때 | 1.5.2 | `suno_remaster_music`만 부분 사용 검토 |

**전면 전환은 첫 조건에서만 한다.** 나머지는 부분 사용이다.

## 9. 열어둔 문 — 하이브리드

전면 전환이 아니라도 쓸 수 있는 경로가 하나 있다. 기록해둔다.

`suno_upload_audio` + `suno_upload_cover`를 쓰면 **우리 음원을 올려서 커버**시킬 수 있다. 프롬프트만으로 생성하면 화성·주제·서사가 다 날아가지만, 완성된 음원을 커버시키면 **구조는 유지하고 음색과 프로덕션만 입힌다.**

| 도구 | 용도 |
|---|---|
| `suno_upload_cover` | 우리 편곡 위에 프로덕션 질감만 |
| `suno_stems_music` | 스템 분리 — 마음에 드는 성부만 골라 씀 |
| `suno_get_wav` | 무손실 출력 |
| `suno_get_midi` | 생성 결과에서 MIDI 추출 → 자체 합성기로 재렌더 |
| `suno_remaster_music` | 마스터링만 |

다만 이 경로에도 두 가지 위험이 남는다. **커버 과정에서 템포가 미세하게 바뀌면 영상 타임코드가 어긋난다.** 그리고 **1970년대 질감이 현대적으로 다듬어질 가능성**이 여전히 있다.

시도할 가치가 있는 시점은 **전곡이 완성된 뒤(1.5.2 이후)**다. 그때는 원본을 그대로 두고 커버본을 A/B로 비교할 수 있다. 지금 하면 구조가 흔들린다.
