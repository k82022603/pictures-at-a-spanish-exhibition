## 1. 먼저 알아 두실 것 — 만든 곳에서 직접 못 삽니다

**Seedance 를 만든 곳은 ByteDance(틱톡 회사)**이고, 그 회사의 판매 창구가
**BytePlus ModelArk** 입니다.

> **그런데 Seedance 2.5 의 API 는 거기서 아직 안 열렸습니다** — 문서에
> *"API access is coming soon"* 이라고 적혀 있습니다 (2026-08-24 확인).

**`API`** 란 **「사람이 웹사이트에서 클릭하는 대신, 프로그램이 직접 시키는 창구」**입니다.
**제가 여섯 장을 자동으로 처리하려면 이게 있어야 합니다.**

**그래서 중개하는 곳을 씁니다.** 같은 모델을 대신 팔아 주는 회사들입니다.

| | 사진→영상 창구 | 값 매기는 법 |
|---|---|---|
| **`fal.ai`** | **문서로 공개돼 있다** | 토큰당 |
| OpenRouter | 있다 | **초당** — 480p $0.1028 · 720p $0.232 |
| BytePlus (만든 곳) | **아직 없음** | — |

## 2. 어디서 사나 — **`fal.ai`**

**`fal.ai` 를 권합니다.** 이유가 셋입니다.

| # | 왜 |
|---|---|
| **1** | **사진 파일을 그대로 올릴 수 있습니다.** 사진을 어디 웹에 먼저 올려 주소를 만들 필요가 없습니다 |
| **2** | **필요한 설정이 다 열려 있습니다** — 해상도(480p/720p/1080p) · 길이(4~30초) · 소리 켜고 끄기 |
| **3** | 창구 규격이 **문서로 공개**돼 있어 제가 바로 붙일 수 있습니다 |

### 우리가 쓸 설정

| 항목 | 값 | 왜 |
|---|---|---|
| 모델 | `bytedance/seedance-2.5/image-to-video` | 사진 한 장에서 영상을 만든다 |
| **해상도** | **720p** | 우리 사진 세로가 **768** 픽셀이다. 그 위는 없는 것을 지어내는 것 |
| **길이** | **5초** | 그녀가 서 있는 컷이 3~6초다 |
| **소리** | **끈다** | **우리 곡이 이미 있다.** 켜 두면 값만 오르고 버리게 된다 |
| 넣는 것 | **실루엣을 얹은 사진** | [23](<23. 그녀를 만든다 — 실루엣과 PoC 가이드.md>) 3절 |

## 3. ★ 검수자가 하실 일 — **넷, 약 20분**

**계정과 결제는 제가 못 합니다.** 아래 넷만 해 주시면 나머지는 전부 제가 합니다.

### ① 계정 만들기 — 5분

<https://fal.ai> 에서 가입합니다. **구글 계정으로 됩니다.**

### ② 카드 등록 — 5분

**선불 충전식입니다.** 쓴 만큼 차감됩니다.

> **⚠ 자동 충전(auto top-up)이 있으면 꺼 두시는 편이 낫습니다.**
> 실수로 많이 돌려도 **정해 둔 금액에서 멈춥니다.**

### ③ **$10 충전** — 2분

**$10 이면 PoC 여덟 건과 본편 여섯 장이 다 됩니다** (6절).
**모자라면 그때 더 넣으시면 됩니다.** 한 번에 많이 넣을 이유가 없습니다.

### ④ API 열쇠 받기 — 5분

사이트의 **`Keys`** 또는 **`API Keys`** 메뉴에서 **새 열쇠를 만듭니다.**
`fal_` 로 시작하는 긴 문자열이 나옵니다.

> **⚠ 그 문자열은 만들 때 한 번만 보입니다.** 창을 닫으면 다시 못 봅니다.
> **바로 아래 4절대로 파일에 붙여 넣으십시오.**

## 4. 열쇠를 안전하게 넘기는 법

**열쇠는 비밀번호와 같습니다.** 그것만 있으면 누구든 검수자님 돈으로 영상을 뽑을 수 있습니다.

### ★ 채팅에 붙여넣지 마십시오

**대화 기록에 그대로 남습니다.**

### 대신 — **파일에 적어 프로젝트 폴더에 두십시오**

**프로젝트 폴더 맨 위에 `.env` 라는 이름으로 파일을 만들고** 아래 한 줄을 적습니다.

```
FAL_KEY=fal_여기에_받은_열쇠를_붙여넣습니다
```

| | |
|---|---|
| 만드는 곳 | `D:\Users\KTDS\Documents\06.과제\MusicVideo\.env` |
| **git 에 올라가나** | **안 올라갑니다.** `.gitignore` 에 미리 막아 뒀습니다 |
| 파일 이름 | **앞에 점이 있습니다.** `env` 가 아니라 `.env` |

**만드셨으면 "열쇠 넣었다"고만 말씀해 주시면 됩니다.** 제가 읽어서 씁니다.

> **다 쓰고 나면 사이트에서 그 열쇠를 지우실 수 있습니다.** 그러면 파일이 새어 나가도
> 아무 일이 안 생깁니다. **PoC 가 끝나면 지우시길 권합니다.**

## 7. 무엇이 잘못될 수 있나

**미리 적어 둡니다. 겪으면 여기에 답을 채웁니다.**

| # | 무엇 | 어떻게 되나 |
|---|---|---|
| **1** | **1024×768 저해상도를 안 받는다** | 실루엣을 얹은 사진을 **먼저 키워서** 넣는다 |
| **2** | **배경을 건드린다** (SSIM < 0.90) | **V2 위반.** 프롬프트를 조이거나 **PixVerse 로 갈아탄다** |
| **3** | **여섯이 다른 사람으로 보인다** | [23](<23. 그녀를 만든다 — 실루엣과 PoC 가이드.md>) 5절 대안 — **움직이지 않는 실루엣 · 그림자 · 만톤만** |
| **4** | **같은 입력에 매번 다른 결과** | **생성물을 반드시 보관한다.** 다시 못 뽑으면 영상을 다시 못 만든다 |
| **5** | **상업적 이용에 조건이 붙어 있다** | 약관을 읽고 **크레딧 표기 의무**가 있으면 유튜브 설명란에 적는다 |

**1·4·5 는 열쇠를 받는 즉시 제가 확인해서 보고합니다.**
