## 이 저장소에 없는 것

**글과 코드만 git 이 갖는다.** 큰 파일은 Google Drive 에 있다.

| | 어디에 | 왜 |
|---|---|---|
| 사진 원본 244장 | **Drive** | 검수자 지시 — **한 곳에서만 관리한다** |
| 음원 · 영상 | **Drive** | git 은 한 번 넣은 파일을 **영원히 기억**하고, 저장소는 **파일당 100 MB 한도**가 있다 |
| 문서 · 도구 · 설계 파일 | **git** | 되돌릴 수 있어야 한다 |

**각 산출물 폴더의 `README.md` 가 둘을 잇는다** — README 는 git 에, 파일은 Drive 에.
