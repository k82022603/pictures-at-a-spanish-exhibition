## 1. 왜 구축계획서가 아니라 PoC인가

구축계획서는 **방식이 확정된 뒤** 어떻게 구축할지를 적는 문서다. 지금은 방식이 확정되지 않았다. 확정할 수 없는 이유는 단순하다 — 2005년 1024×768 사진에 2026년 영상 생성 모델이 통하는지 아무도 모른다.

모델 벤치마크는 대부분 고해상도 입력이나 텍스트 생성 기준이다. 20년 전 콤팩트 디카의 저조도 JPEG를 넣었을 때 어떻게 나오는지는 우리 소재로 직접 확인해야만 알 수 있다.

검증 없이 구축계획서를 쓰면 두 가지 중 하나가 된다. 통하면 운 좋은 것이고, 안 통하면 문서와 그에 따라 진행한 작업이 모두 버려진다. 소프트웨어 개발에서 불확실한 기술 가정 앞에 스파이크를 먼저 치는 것과 같은 이유다.

**따라서 순서는 이렇게 된다.**

```
PoC 계획서 (본 문서)  →  PoC 실행·판정 (G3)
                            ├─ 통과 → 프롬프트 규격서 (운영 문서) → Phase 3 히어로 샷 생성
                            └─ 불통과 → 켄번스 회귀, WBS 3.4 삭제
```

프롬프트 규격서는 G3를 통과한 뒤에만 쓴다. 통과하지 못하면 존재할 이유가 없는 문서다.

## 2. 검증 질문

가설은 반증 가능한 형태로 쓴다. "좋아 보인다"가 아니라 "무엇이 확인되면 합격인가"를 먼저 정의한다.

| # | 가설 | 반증 조건 |
|---|---|---|
| H1 | Topaz 업스케일을 거친 저해상도 사진에서 생성 모델이 **원본 구도를 보존한** 카메라 무브를 만든다 | 첫 프레임이 원본과 구도가 달라진다 |
| H2 | 건축물의 **직선·반복 구조가 무너지지 않는다** | 창틀·아치·기둥이 휘거나 개수가 변한다 |
| H3 | 저조도 야경 사진에서도 **노이즈가 증폭되지 않고** 쓸 만한 결과가 나온다 | 어두운 영역이 뭉개지거나 색 얼룩이 생긴다 |
| H4 | 사진에 **없던 요소가 생성되지 않는다** (환각 억제) | 사람·간판·물체가 추가되거나 하늘이 바뀐다 |
| H5 | 320×240 탱고 영상이 업스케일 후 **화면 전체로 쓸 만하다** | 인물 얼굴이 뭉개져 공연 영상으로 못 쓴다 |
| H6 | 생성 샷과 정지 샷을 한 타임라인에 섞어도 **이질감이 없다** | 생성 샷만 튀어서 편집이 부자연스럽다 |
| H7 | 여섯 도시에서 **같은 실루엣이 같은 인물로** 보인다 | 도시마다 다른 사람처럼 보인다 |

H4가 가장 중요하다. 개인 여행 기록에서 없던 장면이 만들어지면 그것은 화질 개선이 아니라 **기억의 위조**다. 다른 항목은 타협할 수 있지만 H4는 타협 대상이 아니다.

**H4 범위 명확화 (2026-08-05)** — 서사 도입으로 그녀 한 사람은 의도적으로 추가된다. 그러나 H4는 폐기되지 않고 범위가 좁아진다. **배경은 여전히 변경 금지다** — 건물, 하늘, 거리, 사물은 원본 그대로여야 한다. 추가가 허용되는 것은 그녀 하나뿐이고, 그것도 실루엣으로만이다. 자세한 근거는 7.4절에 있다.

## 4. 판정 기준

정량 지표는 스크립트로 자동 측정하고, 최종 채택 여부는 정성 판정으로 결정한다. 정량은 걸러내기용이고 정성이 결론이다.

### 정량 (자동 측정)

| 지표 | 측정 방법 | 합격선 |
|---|---|---|
| 구도 보존 | 생성 첫 프레임 vs 원본의 SSIM | ≥ 0.90 |
| 직선 구조 유지 | Hough 변환 직선 검출 개수 변화율 | ±15% 이내 |
| 시간 일관성 | 인접 프레임 옵티컬 플로우 크기의 표준편차 | 급변 구간 없음 |
| 노이즈 증폭 | 어두운 영역(하위 20% 휘도) 표준편차 변화 | 원본의 1.3배 이내 |

### 정성 (JinYong 판정)

| 질문 | 판정 |
|---|---|
| 이 장면이 **내 기억과 다른가** | 다르면 즉시 불합격. 타협 없음 (H4) |
| 카메라 움직임이 자연스러운가 | 부자연스러우면 켄번스가 낫다 |
| 인물 얼굴 왜곡이 허용 범위인가 | 허용 못 하면 인물 사진은 생성 대상에서 제외 |
| 정지 샷과 섞였을 때 튀는가 | 튀면 생성 샷 수를 줄이거나 그레인으로 통일 |

### 합격선

| 결과 | 판정 | 후속 조치 |
|---|---|---|
| 8개 중 6개 이상 통과 | **채택** | 프롬프트 규격서 작성, 히어로 샷 10~20장 + 그녀 샷 15~25장 진행 |
| 4~5개 통과 | **제한 채택** | 통과한 유형만 사용. 예: 고해상 가로만, 저조도 제외 |
| 3개 이하 통과 | **불채택** | 켄번스로 회귀. WBS 3.4·3.9 삭제 |

T4(최악 조건)와 T7(탱고 영상)은 통과 못 해도 무방하다. 반면 **T3(반복 구조)가 실패하면 그것만으로 제한 채택 이하로 내린다** — 스페인 건축 사진의 상당수가 아치와 기둥의 반복이기 때문이다.

**T8은 별도로 판정한다.** 다른 테스트의 통과 여부와 무관하게, T8이 실패하면 그녀 샷은 BL-17의 대안(그림자 / 만톤 / 벡터 실루엣)으로 전환한다. 반대로 T8만 통과하고 나머지가 실패해도 서사는 살릴 수 있다 — 그녀 샷만 생성하고 나머지는 켄번스로 처리하면 된다. **서사와 화질 개선은 독립된 판정 대상이다.**

## 5. 프롬프트 설계 원칙

H4(환각 억제)를 지키기 위한 규칙이다. 생성 모델에게 **카메라만 움직이라고 지시하고, 장면은 건드리지 말라고 명시한다.**

### 허용 어휘 — 카메라 동작만

```
slow dolly in / slow dolly out
gentle pan left / gentle pan right
subtle parallax, static subject
slow tilt up / slow tilt down
almost imperceptible handheld drift
locked-off shot with slight breathing
```

### 금지 사항 — 프롬프트에 절대 넣지 않는다

- 사람·차량·동물 등 피사체 추가
- 날씨·시간대·계절 변경 ("golden hour", "sunset" 등)
- 물체·간판·장식 추가
- 감정·분위기 형용사 ("dramatic", "cinematic", "epic") — 모델이 이를 장면 개조 허가로 해석한다

### 네거티브 프롬프트 (고정)

```
new objects, added people, changed architecture, morphing,
warping straight lines, altered sky, text, watermark,
face distortion, extra limbs, style change
```

### 파라미터

| 항목 | 값 | 근거 |
|---|---|---|
| 클립 길이 | **3~5초** | 길어지면 환각이 누적된다. 편집 단위도 2초 내외라 충분하다 |
| 모델 | Kling 3.0 (기본), Seedance 2.0 (T5·T7 비교군) | 해상도·캐릭터 일관성 대 레퍼런스 제어 |
| 재시도 | 테스트당 최대 2회 | 3회 이상 걸리면 그 유형은 실패로 간주 |
| 입력 | Topaz 업스케일 후 이미지 | 원본 직접 투입은 별도 대조군 1회만 |

## 7. 등장인물 추가와 립싱크

기획서에서 "새 인물 영상 생성, 등장인물 추가, 립싱크는 외부 도구가 필요하다"고 적은 부분이다. 여기서 용어를 분리해야 한다. 세 가지가 전혀 다른 문제다.

| 구분 | 내용 | 판단 |
|---|---|---|
| **A. 사진 속 인물을 움직이게 하기** | 이미 사진에 있는 사람이 걷거나 고개를 돌리게 만든다 | **PoC T5·T7이 검증한다.** 기록의 진실성을 크게 해치지 않는다 |
| **B. 없던 인물을 추가하기** | 사진에 없던 사람을 새로 넣는다 | **권장하지 않는다.** 개인 여행 기록의 진실성을 훼손한다. H4 위반 |
| **C. 립싱크** | 인물이 노래하거나 말하는 것처럼 입을 움직인다 | **별도 판정.** 보컬 확정(BL-05) 이후에만 논의 |

### B를 권장하지 않는 이유

이 프로젝트의 소재는 20년 전 본인의 여행 기록이다. 없던 사람을 넣으면 "내가 그때 그곳에 있었다"는 기록이 "그럴싸하게 만들어진 장면"으로 성질이 바뀐다. 화질을 올리는 것과 내용을 바꾸는 것은 다른 문제다.

다만 **연출로 명백히 구분되는 경우는 예외**로 둘 수 있다. 실루엣, 그림자, 뒷모습처럼 "이것은 기록이 아니라 표현"임이 분명한 이미지다. 프롬나드 구간에 걸어가는 사람의 실루엣을 넣는 것은 기록의 위조가 아니라 은유다. 필요하다고 판단되면 BL로 등록해 스토리보드 단계에서 다룬다.

### C의 위험

2005년 320×240 영상이나 1024×768 사진의 인물 얼굴에 립싱크를 걸면 결과가 매우 기괴해질 가능성이 높다. 얼굴 픽셀 수 자체가 부족하다. Veo 3.1이 립싱크 최상급이라 해도 입력 해상도가 감당하지 못한다.

따라서 립싱크는 **보컬이 확정되고, 노래하는 인물 샷이 반드시 필요하다고 판단될 때만** 별도 PoC를 세운다. 지금 단계에서는 다루지 않는다.

### 7.4 개정 — 서사 프레임 도입에 따른 판단 변경 (2026-08-05)

위 7.1~7.3의 판단은 유지한다. 다만 **전제가 바뀌었으므로 결론이 바뀐다.** 원래 판단을 지우지 않고 남기는 이유는, 무엇이 왜 바뀌었는지가 나중에 더 중요해지기 때문이다.

#### 무엇이 바뀌었나

| 구분 | 이전 전제 | 변경된 전제 |
|---|---|---|
| 작품의 성격 | 여행 **기록** | 상상 속 동행자가 있는 **이야기** |
| B(없던 인물 추가) | 권장하지 않음 — 기록의 진실성 훼손 | **채택** — 아래 두 조건 아래서 |

#### 왜 진실성 문제가 발생하지 않는가

7.2에서 우려한 것은 "그럴싸하게 만들어진 장면"이 기록을 대체하는 상황이었다. 새 프레임은 그 상황 자체를 만들지 않는다.

**영상이 그녀를 만들어내는 과정을 스스로 보여주기 때문이다.** 2026년의 화자가 2005년 사진에 누군가를 들여놓는 장면이 액자 구조로 제시된다. 관객은 처음부터 그녀가 상상임을 안다. 숨긴 것이 없으면 속인 것도 없다.

#### 채택 조건

| # | 조건 | 성격 |
|---|---|---|
| C1 | **얼굴 없는 실루엣으로만 등장한다** | 절대. 특정한 누군가가 되는 순간 프레임이 무너진다 |
| C2 | **배경은 변경하지 않는다** | 절대. H4의 축소된 형태 |
| C3 | 등장 샷은 전체의 20% 이하 | 운용 |
| C4 | 4악장 세비야에서는 생성하지 않는다 | 절대. 그녀의 유일한 실재는 실제 기록물(플라멩코 영상)이어야 한다 |

C1은 우연히도 7.3에서 지적한 립싱크 위험까지 해소한다 — **얼굴이 없으면 입도 없다.** 그녀는 말하지 않고 노래만 하며, 그 노래는 7악장의 무가사 보칼리즈로 처리된다. 립싱크는 이 작품에서 영구히 불필요해졌다.

#### 7.1~7.3 판단의 현재 상태

| 절 | 항목 | 현재 |
|---|---|---|
| 7.1 A | 사진 속 인물을 움직이게 하기 | 유효. T5·T7이 검증 |
| 7.2 B | 없던 인물 추가 | **조건부 채택으로 변경.** C1~C4 준수 시 |
| 7.3 C | 립싱크 | 유효. 다루지 않는다. C1로 인해 영구 불필요 |
| — | 실루엣·그림자 예외 | 7.2에서 "예외로 둘 수 있다"고 적은 범주가 **본 서사의 기본 표현 방식이 되었다** |

마지막 항목이 중요하다. 프레임을 바꾸면서 새로운 위험을 들여온 것이 아니라, **원래 안전하다고 판단했던 범주를 확장한 것**이다. 원래 판단과 새 판단은 충돌하지 않는다.

## 8. 판정 후 분기

### 채택 시

1. 프롬프트 규격서 작성 — 통과한 유형별 프롬프트 템플릿, 파라미터, 금지 사항
2. 히어로 샷 선정 기준 확정 — 어떤 사진을 생성 대상으로 삼을지 (WBS 3.4)
3. 인물 근접 사진 제외 목록 확정 (BL-12)
4. 예산 재산정 — 히어로 샷 20장 × 재시도 2회 = 최대 $20

### 제한 채택 시

통과한 유형만 쓴다. 예를 들어 T1·T2만 통과하면 고해상 가로 사진 10장만 대상이 된다. 253장 중 고해상은 10장뿐이므로 사실상 그 10장이 전부다. 이 경우 히어로 샷의 효과가 제한적이니 **투자 대비 효과를 다시 판단**한다.

### 불채택 시

- WBS 3.4(히어로 샷 선정·생성)와 3.9(그녀 샷 생성) 삭제 → 임계경로 단축
- **서사는 BL-17 대안으로 유지한다** — 그림자, 붉은 만톤, 또는 벡터 실루엣 합성. 생성 모델 없이도 ffmpeg 오버레이로 구현 가능하다. 표현의 밀도는 낮아지지만 이야기는 성립한다
- Topaz 업스케일은 그대로 진행한다. 이것은 생성과 무관하게 화질에 기여한다
- 켄번스 + 멀티패널 + 그레이딩 + 타이포로 승부한다. 기획서 4.3의 범위다
- BL-08(생성 샷 이질감 조정) 폐기, BL-09(패널 레이아웃)·BL-10(탱고 처리) 우선순위 상승

불채택이 실패는 아니다. **1.5일과 $8.50로 "이 길은 아니다"를 확정하는 것이 이 PoC의 목적이다.** 검증 없이 진행했다면 Phase 3에서 며칠을 쓰고 같은 결론에 도달했을 것이다.
