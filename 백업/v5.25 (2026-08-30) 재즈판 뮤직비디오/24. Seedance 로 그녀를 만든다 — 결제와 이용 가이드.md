## 1. 먼저 알아 두실 것 — 만든 곳에서 직접 못 삽니다

**Seedance 를 만든 곳은 ByteDance(틱톡 회사)**이고, 그 회사의 판매 창구가
**BytePlus ModelArk** 입니다.

> **그런데 Seedance 2.5 의 API 는 거기서 아직 안 열렸습니다** — 문서에
> *"API access is coming soon"* 이라고 적혀 있습니다 (2026-08-24 확인).

**`API`** 란 **「사람이 웹사이트에서 클릭하는 대신, 프로그램이 직접 시키는 창구」**입니다.
**제가 여섯 장을 자동으로 처리하려면 이게 있어야 합니다.**

**그래서 중개하는 곳을 씁니다.** 같은 모델을 대신 팔아 주는 회사들입니다.

| | 사진→영상 창구 | 값 매기는 법 |
|---|---|---|
| **`fal.ai`** | **문서로 공개돼 있다** | 토큰당 |
| OpenRouter | 있다 | **초당** — 480p $0.1028 · 720p $0.232 |
| BytePlus (만든 곳) | **아직 없음** | — |

## 2. 어디서 사나 — **`fal.ai`**

**`fal.ai` 를 권합니다.** 이유가 셋입니다.

| # | 왜 |
|---|---|
| **1** | **사진 파일을 그대로 올릴 수 있습니다.** 사진을 어디 웹에 먼저 올려 주소를 만들 필요가 없습니다 |
| **2** | **필요한 설정이 다 열려 있습니다** — 해상도(480p/720p/1080p) · 길이(4~30초) · 소리 켜고 끄기 |
| **3** | 창구 규격이 **문서로 공개**돼 있어 제가 바로 붙일 수 있습니다 |

### 우리가 쓸 설정

| 항목 | 값 | 왜 |
|---|---|---|
| 모델 | `bytedance/seedance-2.5/image-to-video` | 사진 한 장에서 영상을 만든다 |
| **해상도** | **720p** | 우리 사진 세로가 **768** 픽셀이다. 그 위는 없는 것을 지어내는 것 |
| **길이** | **5초** | 그녀가 서 있는 컷이 3~6초다 |
| **소리** | **끈다** | **우리 곡이 이미 있다.** 켜 두면 값만 오르고 버리게 된다 |
| 넣는 것 | **실루엣을 얹은 사진** | [23](<23. 그녀를 만든다 — 실루엣과 PoC 가이드.md>) 3절 |

## 3. ★ 검수자가 하실 일 — **넷, 약 20분**

## 4. 열쇠를 안전하게 넘기는 법

**열쇠는 비밀번호와 같습니다.** 그것만 있으면 누구든 검수자님 돈으로 영상을 뽑을 수 있습니다.

### ★ 채팅에 붙여넣지 마십시오

**대화 기록에 그대로 남습니다.**

### 대신 — **파일에 적어 프로젝트 폴더에 두십시오**

**프로젝트 폴더 맨 위에 `.env` 라는 이름으로 파일을 만들고** 아래 한 줄을 적습니다.

```
FAL_KEY=fal_여기에_받은_열쇠를_붙여넣습니다
```

| | |
|---|---|
| 만드는 곳 | `D:\Users\KTDS\Documents\06.과제\MusicVideo\.env` |
| **git 에 올라가나** | **안 올라갑니다.** `.gitignore` 에 미리 막아 뒀습니다 |
| 파일 이름 | **앞에 점이 있습니다.** `env` 가 아니라 `.env` |

**만드셨으면 "열쇠 넣었다"고만 말씀해 주시면 됩니다.** 제가 읽어서 씁니다.

> **다 쓰고 나면 사이트에서 그 열쇠를 지우실 수 있습니다.** 그러면 파일이 새어 나가도
> 아무 일이 안 생깁니다. **PoC 가 끝나면 지우시길 권합니다.**

## 8. ★ 개정 — **실제로 써 보고 알아낸 것** (v5.17, 2026-08-24 저녁)

**1~7절은 「이렇게 될 것이다」였다. 이 절은 「이랬다」다.** 앞 절은 그대로 둔다(R3).

### 8.1 값 — **실측**

| | 문서가 적었던 것 | **실측** |
|---|---|---|
| Seedance 720p 5초 | $1.16 | **$2.345** — **두 배였다** |
| 초당 | — | **약 $0.469** |
| **Nano Banana 2 이미지** | (안 적었음) | **$0.08 / 장** |

**그래서 6절의 「$10~25」는 영상 기준이고, 지금 우리는 이미지를 쓰므로
훨씬 적게 든다** — 자세한 것은 [23](<23. 그녀를 만든다 — 실루엣과 PoC 가이드.md>) 8절.

### 8.2 ★ 모델 경로 — **`fal-ai/` 접두사가 없다**

```
bytedance/seedance-2.5/image-to-video      ← 이것이 맞다
fal-ai/seedance-2.5/image-to-video         ← 다른 것. early access · B2B 전용
```

> **★ 뒤엣것의 「I agree」를 누르지 마십시오.** 약관이 *"사업자 고객에게만
> 서비스하며 모든 최종 사용자가 사업자임을 확인한다"* 는 내용이라
> **개인 프로젝트인 우리와 사실이 다릅니다.**

**틀린 경로를 보내도 큐가 받아 놓고 나중에 404 를 낸다** — 즉시 거절이 아니다.
그래서 `Seedance.py` 의 자기검사는 **요청을 안 보내고 규격서만 읽어** 확인한다.

### 8.3 ★ `generate_audio` 의 기본값이 **켜짐**이다

**그냥 부르면 안 쓸 소리에 돈이 붙는다.** 도구에 **끔으로 박아 넣고 자기검사가
확인**한다.

### 8.4 ★ 사람 얼굴이 있는 사진은 **거부된다**

에필로그 15초 요청이 이렇게 돌아왔다 —

> `content_policy_violation` — *"The images or videos provided may contain
> likenesses of real people or other private information that cannot be processed."*

**세고비아 사진 오른쪽의 관광객 둘** 때문이다. **생성 전에 거부되므로 과금은
없다.** 잘라내면 통과한다.

> **우리 사진 244장에는 사람이 자주 나온다.** 앞으로 영상 생성에 쓸 사진은
> **얼굴이 없는 것을 고르거나 잘라내야 한다.**

### 8.5 ★★ 결과 주소를 **손으로 조립하지 말 것**

**이것 하나로 약 $4.70 을 버렸다.**

```
큐 + 모델.split("/")[0] + "/requests/"   →  bytedance/requests/…        ← 틀림
fal 응답의 status_url / response_url     →  bytedance/seedance-2.5/…    ← 맞음
```

**요청은 정상으로 나갔고 fal 은 만들어서 돈을 받았는데, 우리만 결과를 못 읽었다.**
**모델 경로가 몇 토막인지를 내가 가정한 것이 원인이다.**

**같은 병이 한 번 더 났다** — `d["video"]` 를 가정했다가 15초 요청의 응답을
통째로 잃었다(그때는 정책 거부라 과금은 없었다).

> **규칙 — 받은 것을 무조건 먼저 파일로 떨어뜨린다. 해석은 그 다음이다.**
> `에필로그.py` 가 그렇게 한다.

**버린 요청은 fal 대시보드 `Request History` 에 남아 있어 되찾을 수 있다.**
