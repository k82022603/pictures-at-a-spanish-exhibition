# 95. 영상 프로젝트 — 뮤직비디오를 굽는 곳

**Remotion 으로 10분 영상을 만든다.** 2026-08-23 신설.

> **여기서는 아무것도 정하지 않는다.** 어느 사진이 몇 초에 나오는지는
> [`99. 작업 스크립트/뼈대.py`](<../99. 작업 스크립트/뼈대.py>) 가 정해 `뼈대.json` 에 적는다.
> **배치를 바꾸려면 이쪽이 아니라 그쪽을 고친다.**

---

## 1. Remotion 이 무엇인가

**코드로 영상을 만드는 것이다.** *"3분 04초에 이 사진을 넣고 5초 동안 천천히 확대한다"* 를
글로 적으면 영상이 나온다. 웹페이지를 만드는 방식(React)으로 화면을 그리고,
그것을 1초에 30장씩 사진으로 찍어 이어 붙인다.

**개인은 상업적 이용도 무료다** (4명 이상 조직만 유료).

---

## 2. 무엇이 어디 있나

| | 무엇 | git |
|---|---|---|
| `src/Video.jsx` | **그리는 쪽.** 켄번스 · 멀티패널 · 제목 · 악장 이름 · 전환 | **들어간다** |
| `src/Root.jsx` · `src/index.jsx` | 어떤 영상이 있는지 알려주는 것 | 들어간다 |
| **`src/뼈대.json`** | **어느 사진이 몇 초에.** `뼈대.py` 가 쓴다 — **손으로 고치지 않는다** | 들어간다 |
| `public/` | **사진 244장 + 음악. 전부 사본이다** | **안 들어간다** |
| `node_modules/` · `out/` | 꾸러미 247개 / 구운 영상 | **안 들어간다** |

**`public/` 이 git 에 안 들어가는 이유** — *"사진 원본은 Google Drive 한 곳에서만 관리한다"*
(검수자 지시). **사본에도 같은 규칙이 적용된다.**

## 4. 굽는 법

### 눈으로 먼저 본다 — **정지 화면 한 장**

**10분을 굽는 데 20분이 걸린다.** 배치를 바꿨으면 **먼저 한 장만 뽑아 본다.**

```bash
npx remotion still src/index.jsx jeongok out/확인.png --frame=2180
```

실제로 이것이 **두 가지를 잡았다** — 0악장에 마지막 도시가 나온 것, 벽화 위에서
악장 번호가 안 보인 것. **숫자만으로는 못 봤을 것들이다.**

### 화면 안에서 만져 본다

```bash
npm run studio
```

### ★ 전곡 — **소리는 따로 붙인다**

**한 번에 굽지 않는다.** Remotion 이 소리를 같이 넣으면 **AAC 인코더 지연 2048 샘플
(42.67 ms) 만큼 소리가 늦는다.** 2026-08-23 에 실측했고 **다섯 지점 전부 같은 값**이었다 —
드리프트가 아니라 고정 지연이다.

**그래서 영상만 굽고, 소리는 마스터에서 다시 먹싱한다.**
[`review-video`](<../.claude/skills/review-video/SKILL.md>) 스킬 3절이 정해 둔 방식과 같다.

```bash
# ① 영상만 (소리 없음)
npx remotion render src/index.jsx jeongok "out/영상만.mp4" \
  --codec=h264 --crf=20 --muted

# ② 마스터 소리를 붙인다
ffmpeg -y -i "out/영상만.mp4" \
  -i "../산출물/20260822 - 0악장을 다시 만든다/이어붙인 것/전곡 E - 0악장 앞부분을 원본으로 되돌린 것.wav" \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 384k -ar 48000 -ac 2 \
  -shortest -movflags +faststart "out/전곡 뼈대 - 사진 227장.mp4"
```

### ★ 색 범위 — **`--pixel-format` 으로는 안 고쳐진다**

기본으로 나오는 것이 **`yuvj420p` · `color_range=pc`(풀레인지)**다. 프레임을 JPEG 로
뽑는데 **JPEG 이 풀레인지**이기 때문이다. 유튜브 규격은 `yuv420p` 이고
`영상검증.py` 도 그것을 본다.

| 해 본 것 | 결과 |
|---|---|
| `--pixel-format=yuv420p` | **안 먹는다.** `color_range=pc` 그대로 (2026-08-23 실측) |
| **`Config.setColorSpace("bt709")`** | **`yuv420p` · `tv` · `bt709`** ← 이것이 답 |

**`remotion.config.js` 에 이미 넣어 두었다.** 300프레임만 구워 확인한 값이다 —
**35분짜리 전곡을 굽고 나서 틀린 것을 아는 일을 두 번 하지 않으려고 그랬다.**

### 구웠으면 반드시 잰다

```bash
cd ..
python "99. 작업 스크립트/영상검증.py" "95. 영상 프로젝트/out/전곡 뼈대.mp4" \
  --from "산출물/20260822 - 0악장을 다시 만든다/이어붙인 것/전곡 E - 0악장 앞부분을 원본으로 되돌린 것.wav"
```

**통과 기준은 전 지점 0 샘플이다.** `--from` 을 안 주면 **우리 자체 합성판과 견주므로
「어긋났다」가 잔뜩 나온다** — 동기가 아니라 다른 곡과 견준 것이다(2026-08-22 에 실제로 겪었다).

## 5. 걸린 것 · 알아둘 것

| | |
|---|---|
| **`"type": "module"`** | `import` 에 **확장자를 반드시 적는다** — `./Video.jsx`. 빼면 안 뜬다 |
| **한글 글꼴** | `Malgun Gothic` 을 쓴다. 인터넷에서 받아오지 않으므로 **오프라인에서도 같은 그림**이 나온다 |
| **난수 금지** | 켄번스 방향을 **컷 번호로 정한다.** 난수를 쓰면 구울 때마다 달라져 **「어제 것과 뭐가 달라졌나」를 못 가린다**(BL-30 과 같은 이유) |
| 렌더 시간 | 10분 영상에 **약 20분** · 헤드리스 크롬 8개 |
| 파일 크기 | crf 20 에서 **약 460 MB**. 유튜브 권장(8 Mbps) 안쪽이다 |
